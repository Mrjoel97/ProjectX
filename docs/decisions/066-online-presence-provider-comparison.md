# ADR-066: Compare design providers before selecting a default

Date: 2026-10-26. Status: accepted for isolated evaluation; production adoption undecided.

## Context

The owner prefers Kimi K3.1 Pro with Google Stitch for website, landing-page and shop quality, including smooth motion, but requests actual comparison before making both mandatory. The present closed renderer can lose composition fidelity when translating external designs. A model change alone does not remove that limitation.

## Decision

Keep the ordinary model default unchanged. Provide an explicit bounded operator comparison against Kimi alone and Kimi assisted by Stitch. Use identical fictional business facts and available assets, retain provider outcomes and distinguish design proposals from validated rendered pages. External HTML is quarantined evidence, never an executable publication or financial capability.

Credentials remain server-side. Stitch operations are narrowly scoped and server-authorized, with bounded responses, downloads, deadlines and no automatic retries. An uncertain remote outcome is retained for reconciliation. The owner confirmed the staging Stitch account uses included/free credits without paid overage; this declaration does not imply the API reports dollar usage or establish future production pricing.

The original $5 aggregate test ceiling includes prior expenditure. The proposed $2 pilot target cannot override the gateway's larger conservative reservation. Never weaken accounting to make a call fit; admit a bounded attempt only within the remaining aggregate authorization and reconcile actual usage before another attempt.

Renderer v7 adds code-owned CSS motion with immediate readable content, static fallback and reduced-motion support. Existing immutable publications retain their prior bytes. Changing compiler/renderer identity requires fresh qualification, not reuse of old browser receipts.

## Consequences

Stitch can become the preferred design stage if real compiled output wins on quality, usability and operational cost. Keep a provider boundary and report unavailable stages explicitly instead of silently downgrading a job. Whether both providers are mandatory remains undecided until comparative evidence exists. Payment and exact-version publication authority remain unchanged.
