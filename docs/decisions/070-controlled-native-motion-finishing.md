# ADR-070: Controlled native motion finishing

Status: Accepted for implementation, superseding ADR-069's static-typography ceiling.
Date: 2026-10-26

Native finishing profile 2 animates reviewed titles with a bounded eased rise and opacity change,
then holds them readable within the approved interval. An optional `orbit-ring` cue renders a
closed, locally projected and depth-sorted 3D annulus as a decorative hero accent. It is not a
product replica. No arbitrary code, new provider, dependency or generated asset is admitted.

The cue travels through parsing, tenant-owned plan persistence, explicit scene review, the native
approval hash and renderer sidecar checks. The hash also includes the pinned approved brand
revision. Output duration and native audio placement stay unchanged. Actual FFmpeg tests verify
changing projected pixels, title movement, fade intervals and unchanged audio offsets.

Accurate product-mesh rendering remains unsupported. Requests for it require an approved suitable
model, a supported rendering lane and preview evidence; a generated camera orbit must not be
represented as controlled product geometry.

The existing 15-second bottle footage was finished locally at no new provider cost. A direct
Kimi comparison returned valid decks, but production tool-loop qualification did not complete.
The current director remains selected. See the dated comparison report for costs and the one
unresolved subsequent SDK attempt; no paid retry is authorized while that outcome is unknown.
