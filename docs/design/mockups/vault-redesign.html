Knowledge Vault · redesign mock

What changed — colour only. Every feature, control and copy line is the one already shipped.

1 · The canvas stops being teal The vault currently sits on .pane-canvas — two teal radial washes behind the cards. Removed. Plain --canvas, so white cards read as objects on paper, exactly like Approvals and Finance.
2 · Teal gets one job Today teal is the rail, the Refresh button, the active tab, the upload link, the search icon and the aura — six jobs, so none of them read as the action. Now: primary button + active tab. That is all.
3 · Badges become semantic, not decorative The four stat badges were saturated solids picked for variety (#22c55e lime clashes with brand teal). Now soft tint + saturated glyph, each hue meaning something: neutral = a count, green = healthy, blue = storage, violet = structure.
4 · Documents carry their type in colour A left spine + tinted glyph per document type. This is what breaks the green monotony — variety comes from the content, not from decoration.
5 · Status chips untouched ready / processing / pending / extracting / failed keep the exact palette already in DocGrid.tsx. They were never the problem — they were drowning in the surrounding green. The label still carries the meaning, never the colour alone (BRAND §6).
6 · Amber stays reserved --held is the approval gate's alone (BRAND §2). The vault's "processing" chip uses a warmer sand (#b07d2e on #fbf3e4) so it never competes with a held approval — and it passes contrast on paper, which raw --held does not.
