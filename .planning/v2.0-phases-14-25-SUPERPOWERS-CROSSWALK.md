authority. A Superpowers checkbox, progress ledger, or commit label does not close a phase unless it

## Required status contract for new Superpowers work

Every implementation-bearing Superpowers artifact should declare:

- canonical GSD phase (or `unregistered`),
- requirement IDs,
- `design | planned | executing | implemented | verified | superseded`,
- links to the canonical PLAN/SUMMARY/VERIFICATION artifacts,
- remaining live/owner gates and exact evidence files.

Until that metadata exists, the corresponding GSD phase artifacts—not Superpowers checkboxes or
progress prose—determine whether work is open.
