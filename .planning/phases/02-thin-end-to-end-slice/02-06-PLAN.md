       step.workflowId, correlationId, timeoutMs: SEVEN_DAYS, attempt })`, then
       `evt = step.awaitEvent({ name: review:${correlationId}:${attempt}, validator: reviewEventValidator })`.
       - timeout → status `expired`, audit, telemetry(expired), NO delivery, return.
       - reject → status `rejected`, capture optional reason on the request, audit, telemetry(rejected), return.

         On breach the UI stops offering regenerate (approve/edit/reject remain). `ponytail:` MAX_REGENERATE

    4. status→delivering; `await retrier.run(ctx, internal.gmail.send, { requestId })`. If gmail set
       `awaiting_reauth`, the workflow ends in that hold state (delivery re-fires on reconnect). On
       success status→sent; telemetry(sent).
