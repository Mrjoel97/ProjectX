<objective>
Build the intake and live-status surface: the recipient-first submit form (To → Goal →
Attach) with upload-first attachments and inline validation, and the requests list that
watches pipeline status update in real time (INTK-01, BETA-04).

Purpose: recipient first because it is the field with the irreversible consequence; the
live list is what actually demonstrates BETA-04's reactive subscription (you cannot
animate a status that does not exist).

Output: submit form, attachment picker, live requests list.
