# Phase 25.2 — Delete-first UX pass: research

**Source:** rev 5 system audit (`.planning/design/system-audit-2026-09-03-merged.md` §4 G14 / G15 / G16, §5 Track A step 3). The audit promised "ten items" and never listed them; this file is the list, checked against the tree at `d108ff3` (production as of 2026-09-05).
**Rule of the phase:** deletion and copy, not design. No new component, no new dependency, no new route. Every item is one of: delete, hide from non-owners, rename a string, or map an enum to words. BRAND.md §1 voice and §6 accessibility apply to every string.
**Owner decisions in force:** invite-only signup (G16 narrows to copy); free beta; nothing frozen.
