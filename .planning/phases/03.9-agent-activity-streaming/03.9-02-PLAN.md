// ai@7.0.20 — the event shapes. VERIFIED against the installed source, not docs:
//   dist/index.d.ts:3214-3341 (shapes), dist/index.js:2633-2642 (notify), :2895-2995 (dispatch)
type ToolExecutionStartEvent = {
  toolCall: { toolCallId: string; toolName: string; input: unknown };
  messages: ModelMessage[];   // ⚠️ §4 HAZARD — the FULL model context. Never touch.
};
type ToolExecutionEndEvent = ToolExecutionStartEvent & {
  toolOutput: { type: "tool-result" | "tool-error"; output: unknown };  // ⚠️ §4 HAZARD — `.output`
  toolExecutionMs: number;
};
// generateText options (non-experimental names; experimental_onToolCallStart/Finish are the
// DEPRECATED aliases — dist/index.d.ts:3339-3341. Use the new names.):

onToolExecutionEnd?:   (e: ToolExecutionEndEvent)   => void | Promise<void>;

**Three verified SDK properties this plan depends on** (each traced to installed source):
| Property | Evidence | Consequence |
|---|---|---|
| Both callbacks are **awaited** — start completes BEFORE `tool.execute` | `dist/index.js:2633-2642` (`notify` = `await Promise.all`), called at `:2902` / `:2960`,`:2983` | The `running` row is committed and on-screen before the slow tool begins. No ordering hazard. |
| Callback throws are **swallowed** (`try { await cb(e) } catch {}`) | `dist/index.js:2636-2639` | Fail-open: a broken emitter can never break an agent turn. **But it also fails SILENTLY** — see Task 3's behavior block. |
| `onToolExecutionEnd` fires on **tool-error too**, discriminated by `toolOutput.type` | `dist/index.d.ts:3308-3315`, `.js:2955-2983` | Per-tool terminal state is FREE. A throwing tool cannot leave a spinner running. |
