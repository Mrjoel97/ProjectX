## Decisions Made
- **parseSmoke(safeText) over a `smoke` boolean arg:** `digestInbox` takes structured messages so it needs an explicit smoke flag; `draftReply` takes free `safeText` exactly like `draftCockpit`, so the `SMOKE::` sentinel is the natural offline short-circuit and keeps the plan's 4-arg interface byte-exact.
- **originalBody truncated inside draftReply:** the caller (Plan 04) will fetch the body, but the trust boundary is here — defensive truncation reuses the digest's `BODY_TRUNCATE_CHARS` cap (ponytail: reuse the existing constant).
