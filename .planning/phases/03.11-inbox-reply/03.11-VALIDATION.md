> Per-phase validation contract for feedback sampling during execution.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest `^3.2.7` (backend units, `convex-test@0.0.54`) + Playwright `1.61.1` (web E2E) + golden eval runner (`node run-eval-golden.mjs`) |
| **Config file** | `packages/backend/vitest.config.*`; `apps/web/playwright.config.*`; eval cases in `packages/backend/scripts/eval-cases/*.json` |
| **Quick run command** | `pnpm --filter @pikar/backend test <touched-suite>` |

| **Estimated runtime** | ~30–90s backend units; eval runner longer (LLM calls) |

---

## Sampling Rate

- **After every task commit:** Run `pnpm --filter @pikar/backend test <touched-suite>` (cockpitTools / gmail / llmRedaction / cockpit).
- **After every plan wave:** Run full `pnpm --filter @pikar/backend test`.
- **Skill-edit gate:** `pnpm eval:golden --skill cockpit-agent@N` (and `reply-drafter@N` if minted) must be green BEFORE `activateSkill`; rollback is exempt (EVAL-01).
- **Before `/gsd:verify-work`:** Full backend suite green + eval green + live human-verify of an in-thread reply.
- **Max feedback latency:** ~90 seconds (unit tier).
