— read `by_event`; if a row exists `return { inserted: false }`. Then read `by_object_type` for

**Pitfall 1 is why the mutation owns both halves.** An `httpAction` is NOT transactional: an
"insert here, apply there" split lets a crash leave a dedupe row with no effect, and the Stripe
retry is then silently suppressed. Do the insert and every effect in one mutation. No `runAction`,
no `fetch`, no I/O await inside it.

`convex/billingWebhook.ts` needs **no** `lib/allowlist.ts` entry — the guard's regex matches only
lowercase `query`/`mutation` from `_generated/server`, and this file imports `internalMutation`.
Confirm that by running `convex/importGuard.test.ts`.

**4. `convex/http.ts`** — one route, `path: "/billing/stripe/webhook"`, `method: "POST"`.

read `process.env.BILLING_STRIPE_WEBHOOK_SECRET` and the `stripe-signature` header → 400 if either
