## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest 3.2.7 + `convex-test` 0.0.54, `environment: "edge-runtime"` |
| **Config files** | `packages/backend/vitest.config.mts`, `packages/core/vitest.config.ts`, `packages/revenue/vitest.config.ts`, **`packages/billing/vitest.config.ts` (Wave 0 — plan 01 Task 1 creates it)** |
| **Quick run (pure)** | `cd packages/billing && npx vitest run` |
| **Quick run (backend)** | `cd packages/backend && npx vitest run convex/billing convex/env.test.ts` |
| **Full suite** | `pnpm test --force --concurrency=1` |
| **Typecheck** | `cd packages/<pkg> && npx tsc --noEmit` — **SEPARATELY, per package** |
| **HTTP route harness** | `convexTest(schema, modules).fetch(path, init)` — the `convex/httpAuth.test.ts:62,81` idiom, which drives the REAL `httpAction` in memory |
| **Estimated runtime** | pure < 2s; backend billing filter ~15s; full suite several minutes |

**Three traps this repo has already paid for, restated because this phase walks into all three:**
1. `cd` INTO the package. `vitest --root <pkg>` from the repo root breaks convex-test's `_generated`
   glob and fakes mass failures.
2. `pnpm test -- <filters>` DOES NOT FILTER — drop the `--`.
3. A *filtered* vitest run cannot tell you `convex/env.test.ts` is red. It went red twice in Phase 28
   over unclassified provider env names, under a green filtered run, both times. This phase adds
   three `BILLING_*` names. **Always include `convex/env.test.ts` in the filter.**
4. `scripts/check-playbooks.mjs` always exits 0 and blocks forever on bare stdin. Run it as
   `node scripts/check-playbooks.mjs < /dev/null` and **read its STDOUT**.

## Sampling Rate

- **After every task commit:** `cd packages/billing && npx vitest run` **and**
  `cd packages/backend && npx vitest run convex/billing convex/env.test.ts`
- **After every plan wave:** `cd packages/<each touched> && npx tsc --noEmit` (separately) then
  `pnpm test --force --concurrency=1`
- **Before `/gsd:verify-work`:** full suite green + `node scripts/check-playbooks.mjs < /dev/null`
  STDOUT clean + `git diff --stat HEAD -- "*.ts"` to prove the COMMIT contains the work, not just
  the tree
- **Max feedback latency:** ~15 seconds (the backend billing filter)
