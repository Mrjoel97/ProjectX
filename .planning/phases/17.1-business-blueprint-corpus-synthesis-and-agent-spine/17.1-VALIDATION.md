## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | vitest (installed in `@pikar/core`, `@pikar/contracts`, `@pikar/backend`), plus `convex-test` + `@edge-runtime/vm` for adapter tests |
| **Config file** | none needed — colocated `*.test.ts` beside source (`businessProfile.test.ts`, `vaultGround.test.ts` precedents) |
| **Quick run command** | `pnpm --filter @pikar/core test blueprint` |
| **Full suite command** | `pnpm --filter @pikar/core test && pnpm --filter @pikar/contracts test && pnpm --filter @pikar/backend test --maxWorkers=1` |
| **Typecheck** | `pnpm --filter <pkg> typecheck` — **load-bearing**: field-set totality is proven by a compile error, not a runtime assertion |
| **Playbook gate** | `node scripts/check-playbooks.mjs` (Stop hook — `vault.md` + onboarding playbook touched, `Last verified` bumped) |
| **Estimated runtime** | ~15 s quick / ~120 s full |

Convex-test boilerplate to copy (`vaultGround.test.ts:12-22`): `convexTest(schema, modules)` with
`const modules = import.meta.glob(["./**/*.ts", "!./**/*.test.ts"]);`, and
`t.action(internal.vaultGround.vaultGroundHydrated, { tenantId, query })` called with **no identity**
— the explicit `tenantId` is the only scope.

**Windows caveat (playbook):** convex-test files false-red on parallel-fork teardown (*"Cannot set
properties of undefined (setting 'exit')"*). Re-run `--maxWorkers=1` before trusting any red.

**Known pre-existing red, not a regression:** `convex/audit.test.ts` (`auditCounts` unregistered in
convex-test), documented since Phase 2. Do not chase it.

**No framework install needed.** Every fixture is built in-test — no binary fixtures, no fixtures
directory (the Phase 3.8 / 15.2 precedent).

## Sampling Rate

- **After every task commit:** the package's own quick command (`@pikar/core test blueprint` for
  pure work, `@pikar/backend test vaultGround --maxWorkers=1` for the seam) **plus that package's
  `typecheck`** — several requirements here fail only at compile time.
- **After every plan wave:** `@pikar/core` + `@pikar/contracts` + `@pikar/backend` full suites
  (`--maxWorkers=1`), `@pikar/web typecheck`, and `check-playbooks`.
- **Before `/gsd:verify-work`:** full suites green, **then the live gate below**.
- **Max feedback latency:** ~15 s (quick), ~120 s (full).

The live gate is **NON-NEGOTIABLE** (CONTEXT). The repo has the receipts: the 2026-07-26 `pdf-lib`
defect *"was invisible OFFLINE too — Node/vitest recover CJS named exports via `cjs-module-lexer`"*
(`vault.md:3`).

| # | Behavior | Req | Why manual | Instructions |
|---|---|---|---|---|
| L1 | **A real cockpit turn's prompt actually carries the spine** | BLPR-02 | convex-test drives the seam directly; it cannot prove the model saw it | Run a real cockpit turn that calls NO tools (e.g. *"draft an email to Bob"*). Verify from the agent's answer that it knows the business. **Read the evidence, do not assert it should be there.** |
| L2 | **The synthesis call returns valid source indices for the REAL corpus** | BLPR-01 | every offline test uses fixtures | Build a blueprint from the owner's real vault; count how many fields the citation gate DROPS. 0 dropped and 8 dropped are both signals. |
| L3 | **`rag.search` behaves as assumed for the probe queries** | BLPR-01 | the `SMOKE::` seam (`vaultGround.ts:48-60`) bypasses embedding, so **no offline test exercises `rag.search` at all** | Inspect probe hit quality on the real vault. Precedent: the chunk-precision defect was found live (`vault.md:3` item 11). |
| L4 | **Real cost of a synthesis run** | BLPR-01 | `~6 probes × 8000 chars` is an estimate | Read `priceUsage`/`recordSpend` after one live rebuild. |
