## Accomplishments

- `deriveCandidates` loads `business-blueprint` first, returns both guardrail stops as governed
  data, redacts the assembled field/source block, supports an offline zero-spend fixture, and makes
  one strict-schema `generateObject` call before recording actual priced usage.
- `buildBlueprintDraft` reads the tier row before any spend, composes the committed typed profile
  with top graph entities, grounds blank fields sequentially in closed-field order, dedupes source
  documents, citation-validates model candidates, merges through the typed-wins core rule, and
  writes one replace-in-place draft blob.
- `writeDraft` refuses a missing `tenantProfiles` row with `NO_TENANT_PROFILE`, patches exactly
  `blueprintDraft` and `blueprintDraftAt`, never creates a tier or vault document, and leaves the
  live `blueprintSourceDocIds` byte-unchanged.
- A current live blueprint with no Stage-1 drift makes a fully typed profile edit probe-free and
  spend-free. Any unincorporated ready document disables that shortcut so a user-triggered rebuild
  still performs document synthesis.
