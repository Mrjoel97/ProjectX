**Types:**
```ts
export const BLUEPRINT_FIELDS = [
  "name", "oneLineDescription", "stage", "tier", "offering", "targetCustomer",
  "revenueModel", "bindingConstraint", "primaryGoals", "knownConstraints", "entities",
] as const;
export type BlueprintField = (typeof BLUEPRINT_FIELDS)[number];

/** One field's content. `values` has ONE member for a scalar field, N for a list field, and is
 *  NEVER empty — a blank field is `null` on the blueprint, not an empty entry. */
export type BlueprintEntry = {
  readonly values: readonly string[];
  /** What the USER asserted vs what the SYSTEM inferred. Drives the `[stated]` / `[source: …]`
   *  markers in the spine — the agent must not second-guess a stated fact at the user. */
  readonly origin: "stated" | "derived";
  /** Document title backing a derived claim. Present iff `origin === "derived"`. */
  readonly source?: string;
};
export type BusinessBlueprint = { readonly [K in BlueprintField]: BlueprintEntry | null };
```

**The ONE totality table** — this single `satisfies` is what makes the serializer, the diff, the
probe map and the spine caps total at once (research Pattern 1, the `TIER_REASON` idiom). Copy its
reasoning into the doc comment: a `Record<BlueprintField, …>` lookup, deliberately NOT a switch,
because a switch's default branch makes the coverage test vacuous forever.
```ts
type FieldSpec = {
  /** Serializer + spine heading. */
  label: string;
  /** true ⇒ rendered as a bullet list; false ⇒ one inline value. */
  list: boolean;
  /** Per-field char cap applied when rendering the spine. */
  cap: number;
  /** Whether the MODEL may propose this field. false ⇒ never probed, never accepted from a
   *  candidate. `name` (the user names their own business), `tier` (deriveTier owns it) and
   *  `entities` (the graph owns it) are all false. */
  derivable: boolean;
  /** The retrieval probe used when this field is BLANK. null iff !derivable. */
  probe: string | null;
};
export const FIELD_SPEC = { /* 11 entries */ } as const satisfies Record<BlueprintField, FieldSpec>;
```
