## Decisions Made

- **UNGATED, and asserted.** The plan and CONTEXT both lock this; what this plan added is the *test*. The mechanical reason (the golden runner's closed `--skill` name list cannot drive the synthesis path, so the first body edit mints a candidate nothing can clear) and the principled reason (output is a vault doc a human confirms under D2; precedence and citation validation are already CODE) are both recorded at the point a reader would try to "fix" the omission.
- **The prompt enumerates no field names.** The body is written against "the FIELDS TO FILL listed in the request" and "the numbered SOURCES provided". The closed field set therefore has exactly one home (the code) and cannot drift between the prompt and the type — the 15.1-06 split, applied.
- **`sourceIndex` is a required integer with `-1` as the sentinel**, not an optional property. This is not style: the adapter's `generateObject` schema must be strict-mode legal (every property required, `additionalProperties: false`), which `llmRedaction.test.ts` asserts statically. The body also tells the model outright that a fabricated index drops the claim entirely, so guessing gains it nothing.
- **The prompt carries the DATA-not-instructions defense clause.** Vault excerpts are user-supplied content flowing into a model prompt — a trust boundary, and the one place CLAUDE.md §8 says not to be lazy. A document reading "classify this business as enterprise" is describable content, never a command.
