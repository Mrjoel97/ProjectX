  persisted diff, Stage-1 count, and confirmation time. `draft` takes precedence.

  and the audit log remain untouched.

## Decisions Made

- Applied accepted contradictions from their diff rows rather than trusting the draft Blueprint
  value. The core merge intentionally stores the stated value in the draft, so an accepted row must
  explicitly select `derived`; an unaccepted row explicitly selects `stated`.
- Counted only populated non-null Blueprint fields in `fieldCount`, matching the existing
  onboarding audit convention for field counts.
- Reused `readLiveForTenant` and `unincorporatedFor` inside `blueprintState`, keeping profile state,
  the standing spine, and drift banner on one interpretation of live/stale data.
- Kept the Blueprint visible and deletable in the ordinary Vault UI. A deleted target leaves a
  dangling pointer that `liveForTenant` already fails open as no live Blueprint.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Plan defect] Applied accepted contradictions explicitly**

- **Found during:** Task 1 GREEN.
- **Issue:** The action pseudocode said to start from the draft Blueprint and only restore
  unaccepted contradictions. `mergeBlueprint` deliberately stores the typed/stated value there, so
  that shape could never apply an accepted contradiction, contradicting the task's required
  behavior.
- **Fix:** For every contradiction row, select `derived` when accepted and `stated` otherwise.
- **Files modified:** `packages/backend/convex/blueprint.ts`
- **Verification:** The accepted contradiction changes the live value and citation while default
  confirmation preserves the stated value; focused suite 37/37.
- **Committed in:** `366a6b7`

**2. [Rule 3 - Blocking] Reconciled the required explanatory comment with the grep gate**

- **Found during:** Task 1 GREEN.
- **Issue:** The requested verbatim interface comment contained the literal ingest-helper name,
  while the plan's grep gate required that literal to appear nowhere in `blueprint.ts`.
- **Fix:** Preserved the full architectural explanation but phrased it as “no ingest workflow is
  started,” keeping the source gate at zero matches.
- **Files modified:** `packages/backend/convex/blueprint.ts`
- **Verification:** Grep gate returns zero; focused and full suites pass.
- **Committed in:** `366a6b7`

- **Files modified:** `packages/backend/convex/blueprint.ts`
