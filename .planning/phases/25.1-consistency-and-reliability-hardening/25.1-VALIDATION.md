---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | vitest (convex-test in packages/backend; component tests in apps/web) |
| **Config file** | packages/backend/vitest config (existing); apps/web vitest (existing) |
| **Quick run command** | `cd packages/backend && npx vitest run <focused files>` (MUST cd into the package — `--root` from repo root breaks convex-test's `_generated` glob) |
| **Full suite command** | `pnpm gate` (typecheck + test + build, --force) |
| **Estimated runtime** | focused ~30-90s; full gate several minutes |

---

## Sampling Rate

- **After every task commit:** Run the focused vitest files touched by the task (from `packages/backend` or `apps/web` respectively)
- **After every plan wave:** Run `pnpm gate`
- **Before `/gsd:verify-work`:** Full suite must be green
- **Max feedback latency:** ~120 seconds (focused runs)
