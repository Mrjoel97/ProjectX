# 51-03 — Evidence-backed next-action read implemented locally

serviceBrainView derives bounded code-owned next-action hints from missing goals/profile sources, stale or unknown confirmation, uncertain work, user rejection/unreviewed usefulness and the conservative social outcome projection. The ordinary authenticated readSocialService tool consumes this same native view. Its fixed service ID and zero-argument boundary remain unchanged; the read cannot start work or widen tools.

Execution success is not goal achievement. Feedback cannot confirm business facts, overwrite active instructions or start a new cycle. Remaining: actual outcome-grounded agenda/proactive proposal integration, existing rejection/recovery and authenticated behavior acceptance. No universal business-improvement or self-improvement claim follows from this read-only layer.
