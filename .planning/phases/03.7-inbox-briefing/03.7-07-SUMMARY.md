## Decisions Made
- `synopsis` is a plain required string in `digestSchema` — unlike `deadline` it is never absent, so no nullable-and-required + normalization dance is needed.
- Offline smoke digest flags item #1 (not #0) as `newsletter`, keeping #0 as the needsReply/action row — so the offline E2E has both a "Needs you" row and a collapse candidate.
- The synopsis SC-2 scan bounds its block to the `buildCockpitTools` close (not EOF, which `briefInboxBlock()` returns) so `digestInbox`'s own legal synopsis returns don't false-positive, and strips line comments so prose mentioning "return"/"synopsis" doesn't trip it. Mirrors the existing draftCockpit comment-strip precedent.
