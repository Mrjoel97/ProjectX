This note records the narrow correction made after the 2026-09-19 configuration attempt was
consumed by malformed environment bytes. It grants no provider, deployment, spend, or retry
authority and records no successful live evidence.

only closed readiness enums and one aggregate boolean. It never returns or logs a credential,
length, prefix, suffix, or hash. Both provider keys must be nonblank and contain no whitespace or
control characters. The recorded billing posture must be exactly:

- `GOLDEN_OPENROUTER_BILLING=standard`
- `GOLDEN_TAVILY_BILLING=free`
- `GOLDEN_TAVILY_CREDIT_USD=0`

After synchronizing the current functions to the named non-production deployment, run the free
standalone check:

```powershell

```

`--preflight` cannot be combined with run flags. It performs the offline self-check and exactly one
read-only Convex readiness query, then exits before corpus loading, budget creation, fixture seeds,
provider calls, evidence writes, or cleanup. A refusal prints only safe reason codes such as
`openrouter_key_invalid_format`; it never echoes the rejected value.

Only after that command passes, and only under a still-valid explicit one-run authorization, is the
full shared gate command eligible to be invoked:

```powershell

```

The full runner repeats the same readiness query before it loads the corpus or opens
`guardrails:openEvalBudget`. Preflight success is readiness only: it is not a corpus attempt, live
observation, evidence row, gate pass, or permission to retry. Evaluator revision
`2026-09-11.budgeted-evaluator.b860a1fb68954482be8ecf9520d02766eeee347fec8b876e0db0dfb8974b0cca`
