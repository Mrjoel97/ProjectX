<interfaces>
- Mint: `useAction(api.voiceToken.mintClientSecret)` → {clientSecret, expiresAt} (never the key).
- Handshake (client-direct to OpenAI): getUserMedia({audio:{echoCancellation:true,
  noiseSuppression:true,autoGainControl:true}}) → RTCPeerConnection + createDataChannel("oai-events")
  → POST realtime/calls with Bearer clientSecret → read call_id from the Location header.
- Relay: `useMutation/useAction(api.voice.startSession)({callId})` immediately after the handshake
  (Pitfall 1 — the watchdog is armed inside startSession, so callId must arrive).
- Metering: on each response.done (throttled), `api.voice.recordUsage({...tokens})`.
- End: confirm → `api.voice.endSessionClean({sessionId})`.
- Wrap-up: around T-2min, emphasize the countdown AND send a data-channel wrap-up instruction
  (response.create) so the agent starts closing (RESEARCH Pattern 3).
- Use globals.css tokens (BRAND) — no new component library, no hardcoded hex a token covers.
- No new npm dep — raw RTCPeerConnection (~60 lines). The @openai/agents-realtime SDK is a marked
  ponytail escape hatch ONLY if live-verify shows event handling is heavy (name it, don't default).
</interfaces>
