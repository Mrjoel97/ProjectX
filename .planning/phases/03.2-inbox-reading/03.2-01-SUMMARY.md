## Decisions Made
- **Empty-guard first (defense-in-depth):** applyAnswer is public, so an empty/whitespace segment is classified `rejected` before any name path — it can never become an empty-string pendingResolution name.
- **pendingValid over a transient plan field (research Open-Q 1):** holding same-turn valid addresses in EmailIntentState keeps the module pure and testable; it is wiped with pendingResolution on the resolution fold.
- **rankCandidates does not filter by name:** the Gmail search already scoped the records; ranking all From/To/Cc addresses by `count desc, lastDateMs desc` (cap 5) is the lazy-correct default (research Pattern 2). The `name` param is carried for the caller's NameCandidates label.
