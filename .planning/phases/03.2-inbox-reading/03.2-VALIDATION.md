## Sampling Rate

- **After every task commit:** Run `pnpm --filter @pikar/core test` (pure logic — fastest signal)
- **After every plan wave:** Run `pnpm --filter @pikar/core test && pnpm --filter @pikar/backend test`
- **Before `/gsd:verify-work`:** Full suite green + `cockpit-resolve` E2E green
- **Max feedback latency:** ~40 seconds
