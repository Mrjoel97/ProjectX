<interfaces>
Plan 22-01 exposes one presentation-safe public query:

```ts
api.owner.viewer -> { isOwner: boolean }
```

`OptimizerPanel` owns all four owner-only hooks:

```ts
useQuery(api.optimizerConfig.getOptimizerStatus, {})
useQuery(api.skills.candidatesForReview, {})
useMutation(api.optimizerConfig.setOptimizerEnabled)
useMutation(api.skills.activateCandidate)
```

Therefore the security-preserving UI shape is to conditionally mount the whole
`<OptimizerPanel />` section, not to invoke hooks in `OpsPage` and not to style-hide the result.
</interfaces>
