Register a governed, read-only `searchVault` cockpit tool inside `buildCockpitTools` so the Executive
Agent can retrieve from the user's knowledge vault mid-conversation (VGND-01). This is the heart of
Phase 10: it wires the already-built retrieval engine (`vaultGround`, hydrated by Plan 01) to the agent
loop with the full governance envelope — refs-only audit (§4), an untrusted-reference fence (SC2),
fail-open no-match behavior (SC1), and a cross-tenant isolation assertion (BETA-05).

Purpose: the vault becomes readable by the agent — the root S1 dependency the rest of the milestone
builds on — WITHOUT loosening any of the platform's isolation/audit invariants.
Output: the `searchVault` tool, a tiny `vaultSources` content-plane table + adapter, four regression
tests, and the definition-of-done governance docs (two playbooks + ADR-006).
