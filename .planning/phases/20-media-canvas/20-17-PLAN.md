<objective>
Burned captions: transcribe the clean voice takes with word-level timings, rebase those words onto the
assembled timeline using the sidecar's speech anchors, and burn them over `final.mp4` in one more
ffmpeg pass.

Purpose: burned captions are the difference between a reel that works on an autoplay-muted social
feed and one that does not. For the actual product job — social and marketing assets — that is not
decoration.

**And the biggest single simplification available in the whole re-scope lives here.** The reference
implementation's captions path implies a **Python 3 runtime, Whisper model weights (~1.5–3 GB) and a
font fetcher inside the render VM**. Do NOT port that shape. Move the STT to fal — where the adapter,
the auth, the queue, the webhook, the price table and the reconciliation procedure already exist —
keep the timing math in pure TS, and leave the sandbox as **ffmpeg-only**. That removes an entire
language runtime and a multi-gigabyte model from a VM that boots per render, and it costs one price
row and one `kind` arm.

Output: the transcript stage, the pure `.ass` writer, the burn pass, and their offline assertions.
</objective>

**REJECTED and why, so nobody re-opens it:** `fal-ai/whisper` is billed **per COMPUTE second** and
cannot be reserved before it runs — the same structural defect as a per-generated-second TTS model.
It happens to work out cheaper in practice, and *"cheap in practice"* is exactly the reasoning
ADR-011 exists to forbid. `fal-ai/speech-to-text` (NVIDIA Canary) returns plain text with **no
timings** and is therefore useless for captions.

  <behavior>

      at `speechAbsS`. Assert that identity directly — it is the whole contract.
    - Words of type `"spacing"` and `"audio_event"` are DROPPED; only `"word"` survives.
    - A rebased time before its block's `windowStartS`, or after `windowStartS + clipSeconds`, is
      CLAMPED to the window and flagged — never allowed to bleed into a neighbouring block's caption.
    - `toAss(lines, style)` emits a valid `.ass` file: `[Script Info]`, `[V4+ Styles]`, `[Events]`,
      with `Dialogue:` rows in `H:MM:SS.cc` time format and ascending start times.
    - Text is escaped for `.ass` — a narration line containing `{`, `}` or a newline cannot inject a
      style override tag. Assert with a hostile fixture. **This is the one security-shaped thing in
      the file: the text being written is model-authored and passes into a renderer's markup.**
    - Words are grouped into caption lines of at most N characters (default 32) so a line never runs
      off a 9:16 frame.
    - Pure: no Convex import, no `node:` import, no network.
  </behavior>
  <action>
Pure TS, Convex-free (CLAUDE.md §1). Consumes the VALIDATED `AssemblyReport` from
`@pikar/core/assembly` — not a raw sidecar. A caller that has not validated the sidecar cannot even
call this function correctly, which is the type system doing governance work for free.

```ts
export type SttWord = { text: string; start: number; end: number; type: string };
export type CaptionLine = { startS: number; endS: number; text: string };
export function rebaseWords(words: readonly SttWord[], block: AssemblyBlock): CaptionLine[];
export function groupIntoLines(lines: readonly CaptionLine[], maxChars?: number): CaptionLine[];
export function toAss(lines: readonly CaptionLine[]): string;
```

`ponytail:` at the top: *"a ~120-line `.ass` writer instead of a subtitle library. `.ass` is a plain
text format and we emit one style and one event type; a dependency would be more lines of
`package.json` churn than of saved code. The ceiling is that we support exactly the subset ffmpeg's
`subtitles=` filter needs — no karaoke, no positioning animation, no multiple styles. Upgrade path if
that ever changes: a real library, at which point this file is deleted rather than extended."*

The escape function needs its own comment naming what it prevents, because it looks cosmetic:
*"`.ass` treats `{...}` as an inline style override. The caption text is model-authored narration. An
unescaped brace is markup injection into a renderer — harmless today, and exactly the kind of thing
that is not harmless once the renderer changes."*
