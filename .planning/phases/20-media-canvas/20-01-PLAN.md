<objective>
The pure, Convex-free media core: parse a storyboard into N fixed-length blocks with a narration line
each, and price a whole JOB — clips, voice takes, captions STT and the render — against tables keyed
by the exact billing unit each provider actually charges on.

Purpose: this is the money bug's containment, and the re-scope makes it carry two more bugs.
(1) `fal-ai/wan-25-preview` defaults to **1080p**, so an estimate computed at 480p against a submit
that omits `resolution` under-reports by **3×**. (2) `chooseModel:134`'s `Math.max(1, Math.ceil(usd *
100))` cents floor, applied **per line item**, turns a 6-block reel's true $0.012 voice cost into
$0.06 — a **5× over-reservation** that compounds on longer decks (D12a). (3) A voice line longer than
its 10 s window is a HARD ERROR that is only measurable by `ffprobe` in the sandbox — **after $3.00
of clips have been paid for** (delta pitfall 13). All three are contained here, in pure TS, at $0.

Output: `packages/core/src/storyboard.ts`, `packages/cost/src/media.ts` + its provenance fixture,
both with tests, plus the new `docs/playbooks/media.md` and its `watch.json` registration.
</objective>

```ts
export const SHOT_TYPES = ["AI", "SCREEN REC", "TEXT", "VIDEO"] as const;
export type ShotType = (typeof SHOT_TYPES)[number];

export const CLIP_SECONDS = [5, 10] as const;        // Wan 2.5's ONLY accepted durations
export const DEFAULT_CLIP_SECONDS = 10;              // D8's default block length
/** English speech runs ~15 chars/second, so a 10 s window holds ~150. 140 leaves headroom.
 *  Enforced HERE, at parse time, because the provider returns no duration (delta §1.5) and the
 *  overrun is otherwise only measurable by ffprobe — after the clips are paid for. */
export const MAX_CHARS_PER_BLOCK = 140;

export type Block = {
  index: number;
  type: ShotType;
  seconds: number;           // === deck.clipSeconds, uniform by construction
  windowStartMs: number;     // DERIVED: index * seconds * 1000
  description: string;
  narration: string;         // the spoken line for this window
  overlay?: string;
  prompt: string;            // the per-block generation prompt (koda /generate)
};

export type ParsedDeck =
  | { ok: true; clipSeconds: number; blocks: Block[] }
  | { ok: false; reason: "no_deck" | "empty_deck" | "unknown_shot_type" | "bad_duration"
                       | "mixed_durations" | "missing_narration" }
  | { ok: false; reason: "narration_too_long"; blockIndex: number; chars: number };

export function parseBlockDeck(body: string): ParsedDeck;
/** Which blocks draw CLIP money. The ONE place this is decided. */
export function isPaidBlock(b: Block): boolean;   // type === "AI" || type === "VIDEO"
/** Total submitted characters across the deck — the tts MediaSpec's input. */
export function narrationChars(blocks: readonly Block[]): number;
```
