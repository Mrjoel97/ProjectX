<objective>
The pure, Convex-free media core: parse a storyboard into typed shots, and price a whole deck
against a table keyed by the exact `(model, resolution)` pair that will be submitted.

Purpose: this is the money bug's containment. `fal-ai/wan-25-preview` defaults to **1080p**, so an
estimate computed at 480p against a submit that omits `resolution` under-reports by **3×** and the
daily window drains at triple the rate with no test going red. Keying the table by the pair — and
making the submit body a function of the same object the estimate consumed (plan 20-05) — is what
makes that structurally impossible.

Output: `packages/core/src/storyboard.ts`, `packages/cost/src/media.ts`, both with tests, plus the
new `docs/playbooks/media.md` and its `watch.json` registration.
</objective>

    - **Paid vs free:** only `AI` and `VIDEO` cost money. `SCREEN REC` and `TEXT` are instructions to

      refuses decks that would have passed.)
    - **Duration legalisation (research Open Question 4, resolved — see the plan note):** a `VIDEO`
      shot whose duration is not exactly 5 s or 10 s is NOT a video shot. It is emitted as an `AI`
      (image) shot. koda's decks routinely use 1.5–2 s shots and fal accepts nothing but {5,10}.
    - `timeOffsetMs` is derived from the cumulative durations, not trusted from the `Time` column
      (a model's arithmetic is not an input to a price).
    - A malformed deck returns a discriminated failure and NEVER throws (the `resolveSpecialist`
      rule) — a governed stop returns, only bugs throw.
    - An empty deck is a failure, not an empty success.
  </behavior>
  <action>
Pure TS, Convex-free (CLAUDE.md §1). Export:

```ts
export const SHOT_TYPES = ["AI", "SCREEN REC", "TEXT", "VIDEO"] as const;
export type ShotType = (typeof SHOT_TYPES)[number];

export type Shot = {
  index: number;
  type: ShotType;
  durationMs: number;
  timeOffsetMs: number;      // DERIVED, cumulative — never read from the Time column
  description: string;
  overlay?: string;
  prompt: string;            // the per-shot generation prompt (koda /generate)
};

export type ParsedDeck =
  | { ok: true; shots: Shot[] }
  | { ok: false; reason: "no_deck" | "empty_deck" | "unknown_shot_type" | "bad_duration" };

export function parseShotDeck(body: string): ParsedDeck;
/** Which shots draw money. The ONE place this is decided. */
export function isPaidShot(s: Shot): boolean;   // type === "AI" || type === "VIDEO"
export const WAN25_DURATIONS = [5, 10] as const;
```

`default` branch would make a fifth type silently inherit another's behaviour and the coverage test
vacuous forever (the `TIER_REASON`/`armFor` lesson, `packages/core/src/actionType.ts:35-43`).
