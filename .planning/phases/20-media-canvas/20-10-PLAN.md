<task type="auto">
  <name>Task 2: `MediaCanvas.tsx` — art direction, shot tiles, and live status with no ticker</name>
  <files>apps/web/app/(app)/dashboard/workspace/MediaCanvas.tsx</files>
  <action>
A self-querying dumb renderer (the `SourceCard` idiom): `useQuery(api.media.byPlan)` +
`useQuery(api.media.assetUrls)` rather than threading data through props.

**No polling anywhere.** Convex reactivity delivers the webhook's mutation to an open canvas with no
ticker. `ActivityCard:1239` already records the rule: *"Measured server-side … never a
`setInterval`."* If you find yourself writing one, the bug is elsewhere.

Structure:
1. **Art-direction header**, compact: `capsTeal` "ART DIRECTION", then palette swatches (the hexes
   the model authored — these are CONTENT, so they are legitimately inline styles, unlike product
   chrome) with their names, plus mood / lighting / composition as short labelled lines.
2. **`capsTeal` "STORYBOARD"**, then one tile per shot **in `index` order**, each showing its `Time`,
   `Duration`, `Type` and description (`traceText` on the description — the split handle is
   user-resizable and a long description must wrap, not overflow).
3. **Each tile is the BRAND Output card** (`BRAND.md:101-102`): titled card, UPPERCASE type badge
   pill (`IMAGE` / `VIDEO` / `SCREEN REC` / `TEXT`), and the rendered artifact once it lands
   (`<img>` / `<video controls>` from `assetUrls`).
   **18-07 COLLISION:** Phase 18-07 plans the same BRAND Output card in `cards.tsx`. If it has
   already landed, IMPORT and reuse it. If not, build it here in a shape 18-07 can reuse, and say so
   in the summary. Do not ship two Output cards.
4. **Before an asset exists**, the tile shows a live status row using the `.trace-line` class:
   `queued` → "Waiting to start", `submitted` → "Generating… (usually 1–3 minutes)", `failed` →
   the failure code in words, `blocked` → **"Refused by the provider's content check"**.
   Wrap the status region in `aria-live="polite"` (BRAND §6).
5. **Verdict copy, and this is a compliance statement, not a style choice:**
   - `checker_clear` → "Provider safety check: passed"
   - `checker_flagged` → "Provider safety check: flagged"
   - `provider_blocked` → "Refused by the provider's content check"
   - `none_reported` → **"Not checked — this model reports no safety verdict"**
   Never a green tick for `none_reported`. Every Wan 2.5 video lands there, and rendering it as a
   pass makes a compliance claim fal never made. Never colour alone.

`globals.css` tokens only. No component library. No timeline, no transitions, no filters, no layers,
no masking, no audio, no client-side rendering — D7's ceiling.
  </action>
