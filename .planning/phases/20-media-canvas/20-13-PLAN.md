<objective>
The assemble stage's CONTRACT, landed before any of its machinery: the ffmpeg script as a governed
repo file, and a pure validator for the `assembly.json` sidecar that proves a render was governed.

Purpose: D8 makes the sidecar the **proof-of-governed-render** — *"a final video without one was
hand-assembled."* If the sidecar is only checked inside the runner, the runner IS the checker and
there is nothing to fail against. Landing the validator first, pure and Convex-free (CLAUDE.md §1),
is what makes plan 20-15's runner and plan 20-16's chain testable at $0 against a contract they did
not write themselves.

registry row too"* — is **remote code execution**. A registry row is mutable by a database write; a
mutable shell script executed in a VM is arbitrary code. §5 governs PROMPTS. This is CODE. One
sentence in the playbook, one static scan, and the door is shut.

Output: the script, its derived constant, its drift test, the sidecar validator, and the scan.

  <behavior>
    - A well-formed sidecar parses to a typed `AssemblyReport` with `blockCount` blocks.
    - **`overrun: true` on ANY block ⇒ INVALID**, with reason `block_overrun` carrying the index.
      D8 makes an overrunning voice line a hard error; a sidecar that reports one is reporting a

    - A **missing `speech_abs_s`** on any block ⇒ invalid. Without it the captions rebase has no

    - A missing `lead_silence_s` ⇒ invalid, for the same reason.
    - `block_count` disagreeing with the length of the blocks array ⇒ invalid.
    - `clip_seconds` outside `{5, 10}` ⇒ invalid.
    - `total_duration_s` not within a small tolerance of `block_count × clip_seconds` ⇒ invalid.
    - `speech_abs_s` non-monotonic across blocks ⇒ invalid.
    - `speech_dur_s` exceeding `clip_seconds` ⇒ invalid (an overrun by arithmetic, even if the
      script's own `overrun` flag said false).
    - Malformed JSON, an empty file, a JSON array, and `null` each return a DISTINCT reason and
      **never throw**.
    - The validator is pure: no Convex import, no `node:` import, no network.
  </behavior>
  <action>
Pure TS, Convex-free (CLAUDE.md §1 — domain logic lives in `packages/*`, and this is the domain rule
that decides whether a render counts).

```ts
export type AssemblyBlock = {
  blockIndex: number; windowStartS: number; leadSilenceS: number;
  speechAbsS: number; speechDurS: number; overrun: boolean;
};
export type AssemblyReport = {
  blockCount: number; clipSeconds: number; totalDurationS: number;
  gates: readonly string[]; blocks: readonly AssemblyBlock[];
};
export type AssemblyError =
  | { code: "bad_json" | "not_an_object" | "missing_field" | "block_count_mismatch"
          | "bad_clip_seconds" | "duration_mismatch" | "non_monotonic_speech" }
  | { code: "block_overrun" | "speech_exceeds_window" | "missing_speech_anchor"; blockIndex: number };

export function parseAssemblySidecar(raw: string): Result<AssemblyReport, AssemblyError>;
/** The one-line question every caller actually asks. */
export function isGovernedRender(raw: string): boolean;   // parseAssemblySidecar(raw).ok
```
