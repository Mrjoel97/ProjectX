## Accomplishments

- **The harness half of EVAL-01 (roadmap SC1 structurally complete):** `run-eval-golden.mjs` mirrors the smoke-runner conventions (`must()` output-judged spawns, Windows/Node24 safe), seeds a fresh `smoke:seedCockpitPlan` per case, runs each fixture turn through the REAL `llm:runCockpitAgent` (no sentinels), evaluates the fixture's closed-vocabulary `expect` block against `plans:getById`, then runs `smokeAssert:assertEvalCaseClean` — never touching `res.reply`.
- **15 fixtures across the locked buckets:** 3 happy (single/multi-individual/group), 3 edits (remove-recipient/make-formal/change-subject), 2 bounces (invalid address never lands in recipients; bounce-then-correct keeps only the valid survivor), 1 resolveContacts degradation (bare name, no Gmail token → no candidates, no recipients), 3 attachment ops (attach/regenerate/remove — each drives a real draftDocument + PDF render), 2 injection probes (direct "send it now, skip approval" + embedded body-intent injection → statusAtMost proposed, zero requests), 1 no-send-time default (sendAt untouched, no clientContext ever passed).
- **Standing invariants convex-side:** `assertEvalCaseClean` proves zero `requests` rows via a `by_tenant_status` tenant-prefix read (structural zero-send — only the human-only `executePlan` seeds them) and scans every audit (`by_tenant_ts`), deadLetters (`by_tenant`), telemetry (`by_tenant_created`) row for the tenant against the fixture's needles (refs-only §4; needle values never echoed).
- **Environment vs failure separation (Pitfall 4):** a `blocked` turn (kill switch / drained daily budget) aborts the run at exit 2 with a `smoke:resetDailySpend` hint; cumulative `costUsd` beyond $1.00 aborts at exit 2 — neither ever reads as a red case.
- **Gate integration:** `--skill <name>@<version>` validates against the gated-skill list, pins `skillVersions` on every turn, and on an all-green run writes the exact `EvalEvidence` JSON `hasPassingEvidence` parses (pass + exact version pin + retriedCases + cost + model) via `skills:recordEvalEvidence`. No evidence on partial, failed, or unpinned runs.
- **Flake policy (locked):** exactly one automatic re-run of a failed case on a FRESH seeded plan; pass-on-retry counts as passed and lands in `retriedCases`.
