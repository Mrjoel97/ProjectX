## Accomplishments

- **costUsd rides the loop end to end (Pattern 4):** `recordModelSpend` returns the priced USD it consumed (0 on the guarded unknown-model path; spend recording itself byte-identical), `runAgentLoop` sums both attempts into one accumulator and returns `{ reply, costUsd }`, and `runCockpitAgent` propagates it — `costUsd: 0` on the SMOKE no-model path, absent on a governed blocked stop. The eval runner can now enforce its hard per-run cost cap without touching the global (unreadable-from-a-script) rate-limiter window.
- **skillVersions pin closes Pitfall 2:** `runCockpitAgent` gained `skillVersions: v.optional(v.record(v.string(), v.number()))` — an internal-only surface the model can never supply. A pinned cockpit-agent version loads via `internal.skills.getSkillVersion` as the system prompt; the pin threads through `runAgentLoop` → `buildCockpitTools` (append-only 5th param) → `renderAndStore`'s `internal.llm.draftDocument` call (scalar `skillVersion` arg), so `pnpm eval:golden --skill name@version` (plan 04) evaluates the exact candidate body it records evidence against.
- **Fail-closed:** a missing (name, version) pin throws `NO_SUCH_SKILL_VERSION` from `getSkillVersion` — never a silent fallback to the active row. No pin = byte-identical active-skill behavior (existing 6 suite cases untouched and green).
- **Shims extended for offline testability:** `__runCockpitAgentWithScript` accepts the pin and returns the loaded `skillVersion` alongside reply/costUsd; `__invokeCockpitTool` passes the pin into `buildCockpitTools`. The draftDocument pin is exercised offline under a SMOKE safeText (the load happens before the smoke short-circuit).
- runCockpitAgent.test.ts 9/9; cockpitTools + llmRedaction 43/43 (no regression — the seams ride args/returns only, §4 scans unaffected); backend source typecheck clean; check-playbooks exit 0.
