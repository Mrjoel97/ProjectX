<deployment_and_cost>
**THIS IS THE FIRST PLAN IN PHASE 27 THAT COSTS MONEY.** Read this block before running anything.

**DEV ONLY.** Eval evidence is a column on the `skills` ROW with an **exact `(name, version)` pin**
(`skills.ts:484 recordEvalEvidence`, `hasPassingEvidence` at the activation choke point). Rows,
versions and evidence are all per-deployment: a DEV eval can never certify a PROD candidate, and the
version numbers differ between deployments. **This plan publishes, evaluates and (in 27-09) activates
on the DEV deployment only.** Say "dev" out loud in the SUMMARY; do not run any part of this against
prod, and do not record a prod version number anywhere.

**Cost.** ~5 fixtures per pack (capped by 27-04/05/06), six packs = ~30 cases. Measured rates from
`run-eval-golden.mjs`: **~$0.017/case plain, ~$0.21/case when research dispatches.** The runner's
`COST_CAP_USD = 2.0` (`run-eval-golden.mjs:88`) is a per-run cap, evidence only writes on an
**ALL-GREEN UNFILTERED run**, and one teardown crash discards the whole gate. A whole-corpus run is
therefore both over the cap and all-or-nothing.

**So: RUN PER PACK, NEVER `--all`.** One invocation per pack id, one evidence write per pack row.
27-VALIDATION already says a failing pack blocks only that pack, and 27-02 Task 3's runner has per-pack
isolation. Budget ~$0.35-4 per pack per attempt and 3-6 attempts across the phase.

**Live-stack prerequisite.** Requires a **verified-stable `convex dev`** (not `--once`) before the
first paid run — a network blip destabilises it into a retry storm that reads as case FAILURES at
$0.0000 rather than as an env abort. Confirm the deployment is answering and stable, then run.

Marked `autonomous: false`: this plan spends OpenAI (and Tavily, where a fixture reaches search) credit.
</deployment_and_cost>
