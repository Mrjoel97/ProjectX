Settled 2026-08-23 by the readiness audit. Do not re-litigate; build to these.

- **These two are the best-supported packs in the pilot.** Complaint Response and Sales Call Prep are
  the only two whose primary inputs are real agent tools rather than `tenantQuery`-only planes. Keep
  their tool needs to what exists — the temptation to reach for one more source is what starved the
  other four.
- **Packs are LEAF AGENTS.** `llm.ts:4337` (`grantDispatch: toolNames === undefined`) and `llm.ts:4342`
  (`grantSkillAuthoring: toolNames === undefined`): a tool allow-list structurally disables specialist
  dispatch. Neither body may plan around `dispatchResearch`/`dispatchMedia` — the Executive Agent keeps
  composition. Any research framing in the upstream source must be dropped or classified `forbidden`.
- **Capabilities the agent cannot reach are `missing`,** carried by the honest-partial-state contract.
  Do **NOT** add new read tools to close a gap. For these two packs the gaps are: refund/order history
  (no tool at all), CRM facts (the only contact tools are `resolveContacts` — which returns display
  labels, **never addresses** — and `stageCrmWrite`, a staging write, not a read), and Phase 26
  summaries (`tenantQuery`-only).
- **Cap fixtures at ~5 per pack.** The eval corpus is the phase's only real cost, and 27-08 inherits
  the bill per fixture.

**Real seams (there is no `convex/inbox.ts` — it never existed):** inbox context is `llm.ts` `listInbox`
(:3377) and `briefInbox` (:3417), plus `gmail.ts` and `briefings.ts`; the reply path is `replyToMessage`
(llm.ts:4023) which proposes an existing email plan; calendar reads are `listManagedCalendarEvents`
(:2551) / `checkAvailability` (:2780) and the only calendar writes are the proposal tools
`proposeCalendarEvent` (:2876) / `proposeCalendarChange` (:2586); Vault read is `searchVault` (:3615);
created documents go through `createDocument` (:3715) → `internal.vault.insertCreatedDoc` (llm.ts:3840).
Use 27-02's operation matrix as the vocabulary — `existing` / `missing` / `forbidden`, no fourth word —
and never name a tool the matrix does not grant this pack.
