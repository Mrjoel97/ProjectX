<owner_decisions>
Settled 2026-08-23 by the readiness audit. Do not re-litigate; build to these.

- **Both packs stay in the pilot.** Brand Review is one of the two most capability-starved packs and it
  ships anyway, with its gap stated honestly rather than papered over.
- **THERE IS NO TENANT BRAND STORE.** `brandVoice` is a per-plan optional string at
  `packages/backend/convex/schema.ts:757` — a field on a plan row, not a queryable store, and no agent
  tool reads it. The content shelf (`content.ts` `listArtifacts` / `summary` / `artifactById`) is
  `tenantQuery`-only by construction, so it is not an agent tool either. Brand Review therefore
  classifies brand guidance **`missing`** and must say, in every output, exactly what it reviewed
  against (guidance the user stated in this turn, or material `searchVault` returned) and what it could
  not check. **Do NOT build a brand store** and do NOT add a new read tool to close this gap — that is
  scope no plan owns and it inflates the eval corpus.
- **Packs are LEAF AGENTS.** `llm.ts:4337` (`grantDispatch: toolNames === undefined`) and `llm.ts:4342`
  (`grantSkillAuthoring: toolNames === undefined`): a tool allow-list structurally disables specialist
  dispatch and skill authoring. Neither body may plan around `dispatchResearch`/`dispatchMedia`/skill
  authoring — the Executive Agent keeps composition. Drop any upstream orchestration framing.
- **Cap fixtures at ~5 per pack.** The eval corpus is the phase's only real cost, and 27-08 inherits the
  bill per fixture.

**Real seams (there is no `convex/documents.ts` — it never existed):** a created document goes through
the `createDocument` tool (`llm.ts:3715`), which writes via `internal.vault.insertCreatedDoc`
(`llm.ts:3840`); it saves only — it never sends, and it writes markdown plus a derived PDF, never
PowerPoint, Word or slides. Vault read is `searchVault` (`llm.ts:3615`). Use 27-02's operation matrix as
the vocabulary — `existing` / `missing` / `forbidden`, no fourth word — and never name a tool the matrix
does not grant this pack.
</owner_decisions>
