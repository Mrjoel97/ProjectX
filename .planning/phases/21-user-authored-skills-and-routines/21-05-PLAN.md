<interfaces>
The one browser send door is:

```ts
const send = useSendCockpitMessage();
const result = await send({ text }); // no threadId => fresh ordinary thread
registerThread(result.threadId, text);
```

Never call `useAction(api.cockpit.sendCockpitMessage)` directly. The hook supplies the current
trusted IANA timezone and clock at call time; bypassing it regresses calendar/CRM behavior.

  <name>Task 1: Implement bounded tenant saved-prompt CRUD</name>
  <files>packages/backend/convex/savedPrompts.ts, packages/backend/convex/savedPrompts.test.ts</files>
  <behavior>
    - Save trims/refuses blank text, enforces a conservative UTF-8 byte cap, derives a bounded title
      from the first nonblank line, hashes normalized text, and inserts no duplicate for the same tenant/hash.
    - The same text in tenant A and B produces separate rows; neither tenant can list/delete the other's row.
    - List returns newest first with a fixed maximum (20), never unbounded collect.
    - Remove checks exact-row ownership; missing and foreign ids return the same not-found result and mutate nothing.
    - No content is copied to audit/dead-letter/telemetry. Deleting a row touches no thread/message/plan table.
  </behavior>
  <action>
Create a thin default-runtime adapter using `tenantQuery`/`tenantMutation` only. `save({text})`
normalizes line endings/outer whitespace, checks UTF-8 bytes before hashing, derives an 80-character
title from the first nonblank line, queries tenant+hash with `.unique()`, and returns the existing id
on duplicate. Keep the text content-plane; no audit is necessary for this reversible preference.

`list({})` uses `by_tenant_createdAt`, descending order, and `.take(20)`. `remove({id})` reads the
exact row and compares `tenantId`; use one non-oracle not-found response for missing/foreign ids.
Do not accept tenantId, title, hash, createdAt, schedule, trigger, or status from the client.

Use two authenticated users in `convex-test`. Fill beyond 20 to prove the bound and order. Snapshot
agent component threads/plans before delete to prove the mutation owns only `savedPrompts`.

the foreign-id case turn red; restore. Mutation-add the prompt text to an audit payload in `save`
