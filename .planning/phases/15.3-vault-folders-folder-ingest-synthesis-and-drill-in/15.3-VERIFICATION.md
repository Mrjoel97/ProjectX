## Human Verification Steps

Use a small, non-sensitive populated folder in a real Google Shared Drive. Include at least one
readable file; keeping the folder unchanged after the first run allows H3 without another fixture.

1. Open `/dashboard/vault`, choose **Import from Drive**, and browse into the Shared Drive folder.
2. Record the displayed folder/file counts and start the import.
3. Wait for the folder to become complete. Open its digest and confirm it reflects facts from the
   real file, while any captured audit/evidence contains only ids/counts/reason codes.
4. Compare UI member/failed counts with the persisted folder/member rows.
5. Re-import the unchanged folder.

**Expected:** a non-zero provider listing; one completed folder; at least one real exported and
ingested member; a grounded digest; consistent refs-only evidence; then exactly
`Nothing has changed — all N files are current` with no new member row, export fetch, or avoidable
spend on the second run.

If no Shared Drive is available, H1 may be run first against populated My Drive to prove the byte
path, but H2 remains separately required before `VALT-13` and the phase can pass.
