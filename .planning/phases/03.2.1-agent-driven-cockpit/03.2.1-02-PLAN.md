      `{ op: "set"; addresses: string[] }`.
    - Returns `{ ok: true; recipients: string[] } | { ok: false; recipients: string[]; rejected: string[] }`.
    - Test (add valid): `["a@x.com"]` + add `["b@y.com"]` → ok, `["a@x.com","b@y.com"]`, deduped case-insensitively.
    - Test (add invalid): add `["bad@"]` → ok:false, recipients unchanged, rejected `["bad@"]`
      (the address NEVER enters recipients — the trust boundary).
    - Test (add mixed): add `["good@z.com","bad@"]` → ok:false, recipients gains `good@z.com`,
      rejected `["bad@"]`.
    - Test (remove by index): `["a@x.com","b@y.com"]` remove index 1 → ok, `["b@y.com"]`.
    - Test (remove out of range): remove index 5 of a 2-element list → ok:false, recipients
      unchanged, rejected `["#5"]` (or an equivalent index marker — a structural error, not a send).
    - Test (set): set `["c@d.com"]` over `["a@x.com"]` → ok, `["c@d.com"]`; set with an invalid
      member bounces that member and does not replace with the bad address.
  </behavior>
