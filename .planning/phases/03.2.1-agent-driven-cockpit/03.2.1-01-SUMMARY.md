## Decisions Made
- Recipient reasoning is index/label-only in the prompt (`#1: Bob`); raw addresses are never shown to the model and never requested to be echoed — the address-privacy contract is stated in the prompt itself, not just the tools.
- The prompt names the exact tool split (`resolveContacts` for a named person, `addRecipients` for an explicit typed address that the tool validates) so Plans 03–04 wire tools to a prompt that already expects them.
