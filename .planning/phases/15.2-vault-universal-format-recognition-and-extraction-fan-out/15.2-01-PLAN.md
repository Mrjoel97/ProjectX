- A run of `0x00`/`0x01` bytes → `"binary"`.
- A buffer that is 90% printable and 10% control bytes → `"binary"` (the bar is ≥95% printable in

- Empty `Uint8Array` → `"binary"` (never throw; an empty file is not text).

```typescript
export type Container = "pdf" | "zip" | "ole2" | "rtf" | "png" | "jpeg" | "gif" | "text" | "binary";
export type ExtractRail =
  | "pdf" | "image" | "zip"
  | "legacy_doc" | "legacy_ppt" | "legacy_xls"
  | "rtf" | "markup" | "text" | "unsupported";

export function sniffContainer(bytes: Uint8Array): Container;
export function ole2Kind(bytes: Uint8Array): "doc" | "ppt" | "xls" | "unknown";
export function resolveRail(bytes: Uint8Array, mimeType: string, filename?: string): ExtractRail;
```

Implementation notes, in ladder order (§8 — reach for the smallest thing that holds):

- Signature matching is a byte-prefix compare over a small table. Do **not** decode the whole
  buffer to a string to look for magic bytes.
- `%PDF` is searched in `bytes.subarray(0, 1024)`, not only at offset 0.
- The text heuristic: decode `bytes.subarray(0, 4096)` with
  `new TextDecoder("utf-8", { fatal: true })`; a throw means not-UTF-8 → `"binary"`. Then require
  ≥95% of the decoded code units to be printable (tab / LF / CR / and `>= 0x20`, excluding
  `0x7F`). Strip a leading BOM before counting. Empty input → `"binary"`.
- `ole2Kind`: OLE2 directory entry names are UTF-16LE. Search the first 8 KiB for the UTF-16LE
  encoding of `"WordDocument"`, `"PowerPoint Document"`, `"Workbook"`, `"Book"` — build each
  needle by interleaving the ASCII bytes with `0x00` and run a plain subarray search. Check
  `"Workbook"` before `"Book"` (the latter is a substring-adjacent BIFF5 name). This is
  content-based on purpose: it is what lets a MIME-less `.xls` be told from a MIME-less `.doc`.
  `// ponytail: needle scan over the first 8 KiB, not a real CFB directory walk — the upgrade
  path is parsing the FAT/DIFAT if a real file ever hides its directory past 8 KiB.`
- `resolveRail` composition — content FIRST, then the MIME/extension fallback (the locked
  decision: "the sniffed container is an override AHEAD of the existing MIME/extension checks;
  those remain as fallback"):
  1. `sniffContainer` → `pdf`→`"pdf"`, `zip`→`"zip"`, `rtf`→`"rtf"`,
     `png|jpeg|gif`→`"image"`, `ole2`→ `ole2Kind` mapped to `legacy_doc|legacy_ppt|legacy_xls`
     (`"unknown"` → fall through to the MIME fallback).
  2. `text` → refine: `text/html`, `application/xhtml+xml`, `application/xml`, `text/xml`,
     `image/svg+xml`, or a `.html?/.xhtml/.xml/.svg` extension → `"markup"`; otherwise `"text"`.
  3. Still undecided → call the EXISTING `extractionKindFor(mimeType, filename)` and map
     `pdf`→`"pdf"`, `image`→`"image"`, `office`→`"zip"`, `transcribe`→`"unsupported"`,
     `null`→`"unsupported"`. Import it from `./extractKind` (same package, dep-free).
     This is the rung-2 move: the fallback already exists — reuse it, do not restate the MIME table.

`// ponytail:` comment required at the top of the file naming the ceiling honestly: this is a
magic-byte sniff, not a libmagic port; formats whose signature is not in the table fall back to
the MIME/extension answer and, failing that, fail honestly via `"unsupported"` — which after
plan 15.2-03 is a TERMINAL `failed("unsupported_format")`, never a silent pending row.

A second `// ponytail:` note where JSON / YAML / TSV / LOG land on `"text"`: the locked decision

/** Which rail an upload is SCHEDULED onto. Deliberately TOTAL — there is no "don't schedule". */
export type SchedulingRail = "transcribe" | "extract";

/**
 * The scheduling decision, in ONE place for all three callers (vault.vaultUpload,
 * vaultSweep.sweepPendingExtraction, vaultSweep.retryExtraction).
 *
 * Media rides vaultTranscribe by MIME, exactly as before. EVERYTHING ELSE rides
 * vaultExtract.extractDoc — including formats no allow-list here recognises. That is the whole
 * fix: `ctx.storage.get` is ACTION-ONLY (queries and mutations get getUrl/getMetadata), so the
 * magic-byte sniff physically cannot run at a scheduling site (RESEARCH §2). Instead of teaching
 * three mutations to guess, we schedule permissively and let the ONE place that can read bytes
 * decide — where `fail("unsupported_format")` already exists (vaultExtract.ts:200) and, until
 * this change, was UNREACHABLE.
 *
 * The invariant the owner cares about is preserved and strengthened: an unresolvable format is
 * TERMINAL `failed`, never a silent `pending_extraction`. Only its LOCATION moved, from the
 * mutation to the action.
 */
export function schedulingRailFor(mimeType: string, filename?: string): SchedulingRail {
  return extractionKindFor(mimeType, filename) === "transcribe" ? "transcribe" : "extract";
}
