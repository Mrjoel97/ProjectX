## Sampling Rate

- **After every task commit:** `pnpm --filter @pikar/vault test` (pure) or
  `pnpm --filter @pikar/backend test <file> -- --maxWorkers=1` (adapter)
- **After every plan:** full suite command above
- **Before `/gsd:verify-work`:** full suite green **AND** the three Manual-Only rows executed
- **Max feedback latency:** ~20 s (quick), ~90 s (full)

No plan in this phase has three consecutive tasks without an automated verify. The only tasks
without one are the three `checkpoint:human-verify` gates, each of which is immediately preceded and
followed by a task that has one.

      under Convex's exact esbuild flags (read from `convex/dist/esm/bundler/debugBundle.js`) and
      assert the namespace carries real named exports, not just `default`. See RESEARCH §5.
      **Sequenced LAST, not first**, so its failure blocks only SC#3 and never SC#1/2/4/5/6/7 —
      six criteria must not wait behind one dependency spike. On failure the dependency is reverted
      and `.xls` keeps 15.2-03's honest `unsupported_legacy_spreadsheet` refusal with 15.2-04's
      "re-save as .xlsx" remedy.
- [ ] Static scan in `xlsText.test.ts` asserting no dynamic import of the parser and a static one
      present — mirroring the existing `pdf-lib is a STATIC import` scan in `vaultExtract.test.ts`.
