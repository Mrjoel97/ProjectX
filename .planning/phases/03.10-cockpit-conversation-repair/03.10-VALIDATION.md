## Sampling Rate

- **After every task commit:** Run the quick command matching the touched surface (backend test file or web typecheck)
- **After every plan wave:** Run the full suite command
- **Before `/gsd:verify-work`:** Full suite green + one live `pnpm eval:golden --skill cockpit-agent@N` all-green run (the gate)
- **Max feedback latency:** 120 seconds (offline); the live eval run is the one slow sample, at the gate only
