## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Relaxed buildAgentContext's `candidates.matches` to optional**
- **Found during:** Task 2 (web typecheck)
- **Issue:** The Task 1 NAME-ONLY `PlanRow.candidates` widening broke the two `buildAgentContext(plan)` call sites (llm.ts:1583/1671): a name-only row is not assignable to `buildAgentContext`'s param, whose `candidates` required the full `matches` shape. Web typecheck failed with TS2345.
- **Fix:** Made `matches` OPTIONAL in `buildAgentContext`'s own `candidates` param and changed its count to `c.matches?.length ?? 0`. The full row still carries `matches` at runtime, so the "N contact(s) found" count is unchanged; `buildAgentContext`'s span already declared the shape, so the header-hint redaction scan is unaffected.
- **Files modified:** packages/backend/convex/llm.ts
- **Verification:** `pnpm --filter @pikar/web exec tsc --noEmit` exit 0; cockpitTools "surfaces names AWAITING a pick" still asserts "2"; header-hint scan still green.
- **Committed in:** 7ea7d6d (Task 2 commit)

**2. [Rule 3 - Blocking] Added a render-only `data-plan-id` E2E hook**
- **Found during:** Task 2 (E2E authoring)
- **Issue:** The proposed+parked state is (by design) unreachable through the composer/SMOKE ops now that the backend refuses it, and a synthetic seeded plan-thread cannot be opened in the UI (PastChats lists agent threads only; no URL thread param). The regression needs the plan id to force `proposeEmailPlan` on the composer's real agent thread, but no threadId→planId internal query exists and none may be added.
- **Fix:** Rendered `data-plan-id={plan._id}` on the PlanCards grid — a render-only attribute, NOT a plan field/mutation/query — so the spec reads the id from the parked-state DOM and forces the deadlock ROW via `cockpit.proposeEmailPlan`.
- **Files modified:** apps/web/app/(app)/dashboard/workspace/cards.tsx
- **Verification:** Web typecheck exit 0; Playwright discovers the regression at cockpit-resolve.spec.ts:196.
- **Committed in:** 7ea7d6d (Task 2 commit)
