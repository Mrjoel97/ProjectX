## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] pdf.js detaches the ArrayBuffer handed to getDocumentProxy**
- **Found during:** Task 2 (offline scan-fixture test)
- **Issue:** after the unpdf text-layer attempt, the hosted-fallback slice read a ZEROED buffer
  ("No PDF header found") — every scanned-PDF hosted call would have failed in production
- **Fix:** `getDocumentProxy(bytes.slice())` — pass a copy; locked in by the test
- **Commit:** c1cb587

**2. [Rule 3 - Blocking] convex-test scheduled-function teardown hang**
- **Found during:** Task 1 GREEN (first run hung >5 min)
- **Issue:** the seam's `workflow.start` enqueues workpool functions; under real timers they fire
  after the suite and retry-loop against vitest's torn-down module runner (60s resolveId
  timeouts, minutes of drag)
- **Fix:** `vi.useFakeTimers()` per test (tests assert synchronous effects only, vault.test.ts
  precedent); one pure-helper test flips back to real timers for dynamic import
- **Commit:** c359627

**3. [Rule 3 - Blocking] shared local dev deployment already managed by lane-4's CLI**
- **Found during:** live smoke (`npx convex dev --once` → "local backend still running")
- **Issue:** the repo's dev deployment is a LOCAL backend; lane-4's active `convex dev` owns its
  lifecycle — a second CLI manager is refused, and this worktree lacked the `.convex` junction
- **Fix:** created the `.convex` junction (lane-4's established pattern) and pushed via the
  self-hosted seam (`CONVEX_SELF_HOSTED_URL=http://127.0.0.1:3210` + adminKey from
  `.convex/local/default/config.json`, written to this worktree's untracked `.env.local`)
- **Side effect (flagged for the orchestrator):** deployed code is now LANE-1's checkout, so
  `vaultTranscribe.transcribeDoc` on the dev deployment is back to the Wave-0 stub until lane-4
  (or the merge plan) re-pushes. Lane-4's own live smoke had already completed (its audit rows
  + SUMMARY predate the push).

Also fixed inline (test-only): the 400k-char truncation fixture originally used one unbroken
run, which makes the `@pikar/pii` email regex backtrack O(n²) — switched to word-shaped filler
and logged the pii ceiling to `deferred-items.md` (shared package, out of lane scope).
