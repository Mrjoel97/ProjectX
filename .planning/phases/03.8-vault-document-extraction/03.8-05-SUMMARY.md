# Phase 3.8 Plan 05: Lane 4 — Video Transcription Summary

Vault mp4/webm/mpeg (and stray audio/*) uploads now transcribe through the existing hosted rail
(experimental_transcribe, gpt-4o-transcribe, intake.ts shape copied) into the ingestExtractedText
seam — governed, duration-priced, counts-only audited, with honest unsupported-container failure.

## What was built

`transcribeDoc` (packages/backend/convex/vaultTranscribe.ts) — the full Pattern-1 spine replacing
the Wave-0 stub:

1. `guardrails.preCall` gate → governed stop is a RETURN (`markFailed(kill_switch |
   daily_budget_exhausted)`), never a throw.
2. `markExtracting` (honest pill).
3. `getDocForExtraction` + `ctx.storage.get` (bytes never ride args).
4. `SMOKE::transcribe::<text>` sniff FIRST — offline/dev spine, no API call, no spend.
5. Mime-only `TRANSCRIBABLE_CONTAINER_MIME` check — `video/quicktime` etc. →
   `markFailed("unsupported_video_container")` before any byte/API work (the honest-failure
   decision; no eternal pending rows).
6. `experimental_transcribe` (45s abort, intake shape) + `priceTranscription` → `recordSpend`.
7. `scanText` fail-closed gate → Err: `pii_scan_failed` + exactly ONE refs-only
   `vault.extraction_failed` audit row; transcript never persists.
8. Counts-only `vault.extracted` audit: `{ vaultDocId, kind: "video", durationSeconds,
   charCount, truncated }` (§4 — needle-scanned in-test for transcript absence).
9. `VAULT_EXTRACT_CHAR_CAP` truncation → `ingestExtractedText` (raw post-gate transcript,
   `truncated` flag) → ingest workflow → embed/graph → ready.
10. Whole-body try/catch → `markFailed("transcribe_failed")` (static refs-only reason).

Offline coverage (vaultTranscribe.test.ts, 6 tests, sentinel-only — no video fixtures, no
encoder dep): sentinel spine walk, audio/* same-spine, truncation + seam flag, mime-only
quicktime rejection, kill-switch RETURN, PII fail-closed with single refs-only audit row.
