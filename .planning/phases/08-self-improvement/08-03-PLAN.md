    - total below floor (e.g. downCount:5, total:5) → eligible:false, reason:"below_sample_floor" — one/few bad ratings never trigger.
    - rate below threshold (downCount:2, total:20 → 0.10) → eligible:false, reason:"below_threshold".

    - boundary: rate EXACTLY threshold and count EXACTLY floor and cooldown EXACTLY elapsed → eligible:true (inclusive).
    - total 0 → eligible:false, reason:"below_sample_floor" (no divide-by-zero).
  </behavior>
