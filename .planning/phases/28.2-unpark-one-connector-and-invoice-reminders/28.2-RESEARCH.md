## Verdict in one paragraph

G22 is an ACTIVATION with one small code gap, not a build. Every piece exists: four provider lanes as
code, a server-owned gate plane, invoice-reminder selection and drafting, the cockpit tool that stages a
reminder as an ordinary approvable email plan, recovery telemetry, eval cases 42/43, and a workspace
offer panel. All four lanes are sealed `parked` with `approved_production` admission (28-23/28-24), all
eight revenue skill bodies sit as v1 CANDIDATES that the activation choke point refuses without
per-deployment eval evidence (28-28), and the tenant-facing Connections panel hides every parked lane,
so today NOBODY — owner included — can even start the grant that would produce the evidence. The other
session's uncommitted change fixes exactly that last point. The one product gap the code does not
cover: the reminder tool needs an invoice ID the user must type, and no surface ever shows one.
