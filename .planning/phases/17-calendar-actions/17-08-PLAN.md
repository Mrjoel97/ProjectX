Provider rules:

- Google supports conditional update/delete with `If-Match`; mismatch is HTTP 412.
- Graph v1.0 PATCH/DELETE management is enabled only because Plan 17-07's disposable event-specific
  probe proved stale `If-Match` PATCH and DELETE return 412 on this deployment/account capability.
  Revalidate the probe schema/deployment/account hash before enabling the Microsoft branch; generic
  OData or `changeKey` reasoning alone is not an acceptable concurrency basis.
- Graph cancel and delete can send cancellation messages for attendee-bearing meetings. Google
  update/delete can also notify guests. Therefore management is attendee-free only and both adapters
  GET a narrow projection before every write. Do not call `/cancel`; do not add `sendUpdates`.
- Exactly-once update: GET first; if provider state already equals the desired state, return success.
  Otherwise require the expected etag and conditionally write.
- Exactly-once delete: GET first; 404/410 means success. Otherwise require etag and delete.
</context>
