Official Graph v1.0 contracts:

- Availability: bounded `/me/calendarView` query with explicit `$select=start,end,showAs`; use this
  instead of `getSchedule` because the latter is not supported for delegated personal accounts.
- Create: `POST /me/calendar/events`, delegated `Calendars.ReadWrite`.
- `transactionId` is the client idempotency key for repeated create POSTs.
- Event responses expose `id` and `@odata.etag`.
- Microsoft documents event `changeKey` as the event version and GET event returns `@odata.etag`,
  but the v1.0 event PATCH/DELETE pages do not promise `If-Match`/412. Generic OData assumptions are
  insufficient: Task 1 must pay a disposable-account capability probe before Microsoft management.
</context>
