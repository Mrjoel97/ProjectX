# Phase 3.5 Plan 02: Deferred Send — setSendTime Fast-Path Summary

**A governed `setSendTime` agent tool that parses a volunteered natural-language time against the TRUSTED client's clock+zone (§2-D — never the model's), writes `plan.sendAt` only on a resolved future instant and re-asks (no write) on ambiguous/past (SC2), surfaced in the agent context and taught in the `cockpit-agent` skill — scheduling fields provably off the log plane (§4).**

## Accomplishments
- **`setSendTime` tool** (`llm.ts`, mirrors `setSubject`/`draftBody`): `parseSendTime(text, clientContext.nowMs, clientContext.tz)` → `resolved` writes `plan.sendAt` via `patchPlan` and returns the absolute time (`Intl.DateTimeFormat`, user tz) for the model to confirm; `ambiguous`/`past` re-ask with NO write (SC2); `none` notes immediate-on-approve; absent `clientContext` (off SMOKE) defers to the plan-card date picker rather than invent a clock.
- **`clientContext {tz, nowMs}` threading** — a NEW optional 4th arg on `buildCockpitTools`, an optional arg on `runCockpitAgent`, and an optional arg on `sendCockpitMessage` (`cockpit.ts`), all append-only so every existing caller is unchanged. - **`buildAgentContext` Send-time line** — `sendAt?: number` added to the param type + an optional `tz` 2nd arg; resolved → the absolute instant in the user's zone, none → `(immediate on approve)`.
- **SMOKE op** — `sendTime=<expr>` added to `AgentSmokeOp`/`parseAgentSmoke`/`runAgentSmokeOp`; `runCockpitAgent` pins `{tz:"UTC", nowMs: SMOKE_NOW_MS}` on the smoke path and builds the tools after parsing the op, so `SMOKE::agent::sendTime=in 3 hours` resolves deterministically offline.

## Decisions Made
- **`buildAgentContext` gets a `tz` arg, not a stored field:** the absolute send time must render in the user's zone, but tz is a per-turn client fact (not a plan-row column). It rides as an optional 2nd arg (default UTC), matching how `clientContext.tz` threads everywhere else.
- **SMOKE clock pinned at 2020-01-01T12:00:00Z:** a fixed `now` so `sendTime=in N hours` resolves to a deterministic future instant offline (and `today at 8am` is deterministically past). Tools are built AFTER parsing the smoke op so the pinned context reaches `setSendTime`.
