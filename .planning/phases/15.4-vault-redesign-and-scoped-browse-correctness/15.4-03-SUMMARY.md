## Decisions Made

- Content state and action capability are separate pure outputs. A missing or foreign projection can
  therefore explain unavailability without making any mutation or signed-download affordance active.
- Delete confirmation is structural: the presenter does not create a destructive descriptor until
  the confirmation state is already true.
- Existing Plan-02 Vault-scoped tokens were sufficient. No global CSS, shared pane/clay contract,
  component dependency, backend query or schema widening was needed.
- Dropzone, PreFlight and DriveBrowser received semantic wrappers and scoped token usage only; their
  existing file caps, sequential transfer, original-manifest reservation, custom Drive traversal and
  import callbacks were deliberately unchanged.
