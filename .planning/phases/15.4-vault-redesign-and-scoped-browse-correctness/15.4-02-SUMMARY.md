## Decisions Made

- Folder browse is a provenance scope, not a category view. It sends `folderId` without a root
  category so search matches the complete member list shown beneath the folder breadcrumb.
- Search applies results only when both a monotonic sequence and the folder/category/query identity
  still match; clearing, changing category or changing folder invalidates every older response.
- The browse state has independent content, ingest and digest axes. Processing/failed-member and
  stale-digest warnings therefore coexist with populated or empty content instead of replacing it.
- All new visual rules are scoped to `.vault-nord-edge` or `vault-*` classes. Existing global
  `.pane-canvas`, `.clay-card` and `.clay-dropzone` contracts were not edited.
- Category tabs remain count-free. The bounded `vaultStats` window is used only to distinguish a
  truly empty root from an empty category and is never presented as an exact category aggregate.
