## Decisions Made

- A dedicated `ownedSearchDocsMeta` resolver has the smallest blast radius: it carries `folderId`
  for the bounded search candidates while leaving grounding's order-sensitive `ownedDocsMeta`
  byte-identical.
- Folder validity is checked inside the tenant-scoped metadata hop. Missing and foreign folder rows
  both yield `[]`, avoiding an ownership oracle without exposing a second public error state.
- Resolver-only folder metadata is removed through an explicit final projection, so no `text`,
  `tenantId`, hash, filename, or `folderId` reaches the public result.
