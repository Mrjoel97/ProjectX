## Task 1 — the live probe, and what it changed

One submit, nine polls, one content fetch. **`usage.cost` $0.490000.** Full transcript in
`33.1-PRICE-EVIDENCE.md`; the five settled questions in summary:

| Question | Answer |
|---|---|
| Does `duration: 7` work? | **Yes.** A finished 7-second MP4. The premise of ADR-027 holds. |
| Submit field names | `duration` (number) / `resolution` (tier) / `aspect_ratio` — **not** `seconds` / `size` |
| Terminal status vocabulary | `pending` ×8 → `completed`. **No `queued`, no `in_progress`, ever.** |
| Does our self-constructed poll URL work? | Yes, and `polling_url` is byte-identical to it |
| `usage.cost` vs the price row | **$0.49 against `7 × $0.07 = $0.49` — exact to the cent** |

Completion took ~90 s for a 7 s clip, comfortably inside the 180-attempt (30-minute) ceiling.

### The probe changed the adapter twice, and both changes were the plan being wrong in a useful way

**1. "Copy `pollOpenAiVideoTask` branch for branch" would have shipped a dead pipeline.** The Sora
poller enumerates `queued | in_progress` as non-terminal. OpenRouter emits **`pending`**, which is on
neither list — so a faithful copy would land `provider_failed` on the *first* poll of *every* job,
behind a fully green suite. The live poller inverts the test: `completed` and `failed` are the only
terminal states, and **anything else reschedules** — an unparseable body and any status this vendor
adds later included. Fail-open toward retrying is safe only because the same 180-attempt ceiling
bounds it: an unrecognised state costs a delay and then `poll_timeout`, never an unbounded loop.

This is the defect class this repo already has a name for — *a check that cannot fail* — arriving
from the opposite direction: a check that **always** fails, on a path no offline fixture would have
questioned, because the fixture would have been written from the same wrong vocabulary as the code.

**2. The trust boundary resolved more strongly than the plan's fallback allowed.** The plan
anticipated having to accept `polling_url` and guard it with a `hostname === "openrouter.ai"` check,
the `wanBaseUrl()` shape. An extra free call settled that it is unnecessary:

| Fetched | Result |
|---|---|
| `GET /videos/{id}` — ours | `200`, full status body |
| `polling_url` from the 202 | byte-identical to the above |
| `GET /videos/{id}/content?index=0` — ours, our bearer | `200`, `video/mp4`, **4 471 786 B**, magic `ftypisom` |
| `unsigned_urls[0]` **without** the bearer | **`401`** |

So `unsigned_urls` is a **misnomer** — it is an ordinary authenticated endpoint on `openrouter.ai`,
not a pre-signed asset link, and following it would have meant sending our credential to whatever
host a provider response named. **No provider-supplied URL enters the system at all.** `polling_url`
is deliberately absent from the poller's scheduler args. Not accepting a foreign value is strictly
stronger than host-checking one, and here it cost nothing.

A test feeds a response naming `evil.example.com` in **both** `unsigned_urls[0]` and `polling_url`
and asserts every resolved fetch host is `openrouter.ai` — so the decision is falsifiable rather
than merely commented.

## Task 2 — the adapter

- **`buildSubmitBody`'s video arm** now emits `{model, prompt, duration, resolution, aspect_ratio}`.
  All three priced dimensions travel, per the function's own contract. `aspect_ratio: "9:16"` is a
  pinned wire field (the video twin of `voice` on the tts arm) reproducing exactly the geometry
  Sora's `720x1280` requested — the migration changes the transport, not the picture.
  **`generate_audio` is never sent**: Grok has no native audio, narration is muxed separately in
  `assemble_final.sh`, and a dimension the price table cannot see is the money bug that doc comment
  exists to prevent. A test asserts its absence and `size`'s.
- **`submitLine`** POSTs JSON to one host with two paths. The `FormData` construction is gone with
  the endpoint that wanted it.
- **The credential collapsed to one read**, and that is a deletion rather than a change. 33.1-03
  keyed the env read on `spec.kind` because the two visual kinds then had two vendors; both are now
  OpenRouter, so a ternary would select the same value on both arms. A branch that cannot differ
  hides the fact that it cannot. Still ABOVE the fixture short-circuit, so offline runs keep
  catching a missing credential.
- **`pollOpenRouterVideoTask`** is a third sibling, marked `ponytail:` with its ceiling (three
  near-identical pollers) and upgrade path (extract only when a FOURTH arrives **and** all four
  still agree branch for branch — they do not today, and finding 1 above is why).
- **The Sora SUBMIT is deleted; the Sora POLLER is retained**, with a comment saying they are
  different decisions. Retained so a job submitted before this deploy can still land on a scheduled
  continuation that already names the function. Not a fallback — the endpoint will not exist. Its
  expiry is explicit: **deletable after 2026-09-24.**

## Task 3 — the flag, and the mutation that earns it

`succession.replacementWiredUp: true` and `status: "migrated"` ship in `385f49e`, the same commit as
the submit path.

**The mutation the plan mandated, run and restored:**

| With flag `true` and the video arm reverted to `api.openai.com` | Result |
|---|---|
| `packages/cost` | **92/92 GREEN** |
| `packages/backend/convex/media.test.ts` | **4 failed**, incl. the A7 pairing |

That asymmetry is the entire argument for asserting the flag and the resolved hostname **in one test
body**. The runway tripwire cannot see routing and never could — it stands down on a flag alone.
Split into two tests, the flag half would pass over a dead endpoint, which is exactly the failure
`7012068` re-keyed the tripwire to close, reappearing one level up.

**A8 is asserted on resolved URLs, looped over both visual kinds**, so a third kind added without a
routing assertion is visibly missing. `api.openai.com` still appears 5× in `media.ts` and every
occurrence is legitimate — TTS, STT, and twice in the retained poller — which is why the source scan
is a reading aid and the runtime assertion is the gate.

**A5's landing leg is asserted on money, not on a column.** `storeAndLand`'s `actual` is not stored
verbatim; it feeds `repriceUsd`. So the test asserts `actualCents: 49` — `7 × $0.07`, which is
**exactly what the live probe was invoiced**. A poller passing a default `4` would read 28.
