<objective>
Move the video duration grid from sora-2's `4, 8, 12` to grok-imagine-video's `1-15, any integer`,
in all three places it is encoded, and re-key the runway tripwire so repinning the default model
cannot silence it.

Purpose: the duration grid is the reason the owner chose Grok. `1-15 any integer` **retires the
`illegal_generated_duration` failure class outright** — the second of the two defects hit live on
2026-08-30. This plan lands the constants and the arithmetic; plan 33.1-05 lands the submit path
and only then may flip `succession.replacementWiredUp`.

Output: grok price rows and grid; `MEDIA_DEFAULT_VIDEO` repinned; `GENERATED_CLIP_SECONDS` widened;
a tripwire that a repin cannot disarm; **a generated-seconds ceiling that restores in code the
guarantee the wider grid destroys**; every derived number recomputed rather than deleted.

**Four tasks, not three, and that is deliberate.** Task 4 was added by owner decision on 2026-08-30
after this plan was first written (see `33.1-CONTEXT.md`, "The generated-seconds cap"). It is not
split into its own plan because the two candidate homes both collide: a wave-3 sibling would write
`packages/cost/src/media.ts` alongside Task 1, and a wave-4 sibling would write
`packages/backend/convex/media.ts` alongside plan 33.1-05. The four tasks are each small edits to
one money boundary.

Fully offline and runnable in this worktree. No live stack, no spend.

**A5's submit leg is asserted in plan 33.1-05.** This plan owns the criterion because this is where
the refusal class dies; 05 proves the same seconds reach a provider.
</objective>
