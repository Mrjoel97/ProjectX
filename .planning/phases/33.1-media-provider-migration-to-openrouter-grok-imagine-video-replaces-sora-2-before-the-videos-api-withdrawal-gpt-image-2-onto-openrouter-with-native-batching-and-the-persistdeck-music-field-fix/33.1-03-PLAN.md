<objective>
Move the still-image plane from `api.openai.com` to OpenRouter, same `gpt-image-2` model, and
replace the self-described "conservative" `$0.01` price row with a number OpenRouter actually
billed.

Purpose: ADR-024's image half stands — only the transport and the key change. The OpenAI account is
out of credit, so today this path buys nothing at all. `data[0].b64_json` is byte-identical to what
`submitLine` already parses, so this is close to a URL-and-key swap; the part that is NOT a swap is
the price, because OpenRouter bills this model per output token and the existing constant was
guessed, not measured.

Output: images generate through OpenRouter; the price row is evidence-backed; the env manifest tells
an operator the truth about which key the media plane needs.

**Runnable in this worktree** (the tests stub `fetch`), **except Task 1**, which makes one real
paid call and needs the owner's key and authorisation.

**The verified OpenRouter image contract** (PRD, confirmed by direct call 2026-08-30):

```
POST https://openrouter.ai/api/v1/images
Request  { model, prompt, n?, aspect_ratio?, size?, quality?, output_format?, seed? }
200      { created, data: [ { b64_json, media_type } ], usage: { ..., cost } }
```

For `openai/gpt-image-2` this endpoint advertises: `aspect_ratio` includes `9:16`;
`quality` in `{auto,low,medium,high}`; **`n` range 1-10**.
