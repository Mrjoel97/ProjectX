### Gotchas that have cost this repo real time — do not rediscover them

- **`pnpm test -- <filter>` does not filter.** Drop the `--` or run vitest directly. A "filtered"
  run that silently ran everything has been mistaken for a targeted green before.
- **`vitest --root <pkg>` from the repo root breaks convex-test's `_generated` glob** and fabricates
  mass failures. `cd` into the package.
- **Always baseline by FAILURE COUNT before trusting a mutation run.** A standing red elsewhere
  looks identical to a new one.
- **Backend vitest exiting 1 while thousands pass is a Windows-only artifact** — green on Linux CI.
  Read the failure count, not the exit code.
- **Read a gate's exit code on its own line**, never through a pipe.

## Falsifiability Notes

Three specific traps this phase is exposed to, each with the shape that would hide it:

1. **The `music` fix can be tested vacuously.** A test that asserts `persistDeck` succeeds without
   ever passing `music` is green before and after the fix. The RED must be observed with the field
   present, and the assertion must name the field.
2. **`succession.replacementWiredUp = true` is a self-certifying flag.** Setting it turns the runway
   tripwire green whether or not anything was wired — that is exactly the failure `7012068` was
   written to close (`status !== "decision_pending"` went green on an ADR alone). It must be set in
   the same commit as a landed submit path and price row, and the phase should assert the submit
   path independently rather than trusting the flag.
3. **A source scan for `api.openai.com` proves spelling, not routing.** A9's real check is that the
   video and image adapters resolve to an OpenRouter base at runtime, asserted on the resolved
   value, not on the absence of a string.
