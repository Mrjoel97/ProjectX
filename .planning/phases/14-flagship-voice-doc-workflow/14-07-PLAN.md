<objective>
Build the front door and the in-call context: a "Discuss by voice" action on a ready vault document,
honestly gated on its ingestion status, and a slim strip naming the document under discussion.

Purpose: the CONTEXT decision is that the vault page IS the entry point — no new upload surface, no
doc picker in the pre-flight. The status gating is the first of the phase's four honesty moments:
never open a grounded conversation the agent cannot ground, and never burn capped 15-minute time on
a document that is still being read.
Output: vault → `/dashboard/voice?doc=<id>` → a live session that names its document.

export const docContext = tenantQuery({
  args: { docId: v.id("vaultDocuments") },

Read the row, return `null` when `row.tenantId !== ctx.tenantId` (fail-closed, the `vault.getDoc`

`text`, so the voice page would pull a book-sized blob to render a title (RESEARCH Open Question 6).

business holding it. Add a `ponytail:` comment saying exactly that.
