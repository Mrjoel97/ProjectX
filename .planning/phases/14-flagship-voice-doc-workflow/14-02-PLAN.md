/** The RAW model object — deliberately carries NO citation, route or verdict field. */

};

  verdict: "gaps" | "healthy" | "insufficient";

  raw: RawDocReview,
  doc: { id: string; title: string },

`shapeDocReview` rules, all in code (RESEARCH Pattern 4 — this is what buys three SC-critical
properties for free, mirroring `voice.md`'s existing invariant that the transcript is welded onto
the brief in code, never model-authored):
1. Drop findings whose `section` is not in `DOC_REVIEW_SECTIONS` and whose `confidence` is not
   `high|medium|low`. Do not coerce — a malformed finding is dropped, never guessed.
2. Weld `citationDocId`/`citationTitle`/`source: "vault"` onto every surviving finding from the
   `doc` argument. The model has no citation field to omit or invent (Success Criterion 2).
3. Weld `route: DOC_GAP_ROUTE` and `playbook: DOC_GAP_PLAYBOOK` onto every gap, plus a dense 1-based
   `leverageRank` in the order given, plus the same `citationDocId`. `reason` and `proofMetric` come
   from the model because `buildMemo` prints them as the memo's "Why this first" / "Done when"
   sections — but they are prose only, never a figure the review did not ground.
4. **Honesty rule (the code half of Success Criterion 2):**
   `findings.length === 0` ⇒ force `gaps = []` and `verdict = "insufficient"`;
   else `gaps.length === 0` ⇒ `verdict = "healthy"`;
   else `verdict = "gaps"`. Comment it as the Phase-12 engine's rule, restated — a gap can never be
   fabricated out of an unread document, and "healthy" can never be reached by emptiness.
