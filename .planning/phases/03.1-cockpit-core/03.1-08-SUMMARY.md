## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Added backend `listThreadMessages` query**
- **Found during:** Task 1 (ChatPane thread render)
- **Issue:** `@convex-dev/agent/react` `useThreadMessages` requires a public query taking `{ threadId, paginationOpts }` and returning `PaginationResult<MessageDoc>`. No such query existed anywhere in the backend (grep clean), so the chat pane — and the plan's `contains: "useThreadMessages"` must-have — could not function.
- **Fix:** Added `listThreadMessages` as a `tenantQuery` in `cockpit.ts` (where `cockpitAgent`/`components.agent` already live): paginated `listMessages(ctx, components.agent, {...})`, guarded on the tenant-scoped `plans` `by_thread` row so a thread is only listable by its owner (no cross-tenant read). Static list — no `streamArgs`/`syncStreams` (ponytail ceiling noted).
- **Files modified:** packages/backend/convex/cockpit.ts
- **Verification:** `pnpm --filter @pikar/web typecheck` clean (the web app consumes the new api ref); cockpit.ts compiles clean under `pnpm --filter @pikar/backend typecheck` (only pre-existing `*.test.ts` errors remain).
- **Committed in:** `975394b` (Task 1 commit)
