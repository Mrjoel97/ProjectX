## Decisions Made
- **draftCockpit writes no audit/telemetry:** the seam has no thread/correlationId (only `safeTextHash`), so meaningful correlation-scoped logging belongs to the caller (plan 07) which owns the thread + plan/requests rows. Emitting no log makes the draft path redaction-safe by construction and keeps the seam thin (ponytail). Add a `usage` return + caller-side OPSG-01 telemetry when plan 07 needs chat-draft cost counts.
- **reportForPlan joins requests → gmail.sent audit:** messageId comes from the row's `gmail.sent` audit payload (queried by correlationId), never stored on the plan.
- **DEFAULT_MODEL primary + CHEAP_MODEL fallback:** draftCockpit's signature carries no model (the guided chat picks none per turn), unlike the pipeline's `draftUncached`.

## Deviations from Plan

The plan's Task 2 text implied draftCockpit would audit `llm.called` like `draftUncached`. I dropped the audit calls — see Decisions above. This was NOT a bug fix but a scoped design refinement forced by a harness reality:

**1. [Rule 3 - Blocking] convex-test cannot run `audit.log` (unregistered aggregate component)**
- **Found during:** Task 2 (writing cockpitDraft.test.ts)
- **Issue:** `audit.log` calls `auditCounts.insert` (@convex-dev/aggregate). convex-test 0.0.54 requires explicit `t.registerComponent` (no auto-registration), which no test in the repo does — so ANY test path reaching `audit.log` throws `Component "auditCounts" is not registered`. Existing tests (guardrails, etc.) all return before `audit.log`; `audit.test.ts` itself is silently red since the Phase-2 aggregate landed. A cockpit-draft that audited would be untestable offline.
- **Fix:** draftCockpit emits no audit itself (the design was already better this way — no correlationId to key on). The draft path became redaction-safe by construction and the test suite is green.
- **Files modified:** packages/backend/convex/llm.ts
- **Verification:** `vitest run convex/cockpitDraft.test.ts` → 3 passed; `llmRedaction.test.ts` (static scan) still green.
- **Committed in:** `90b5381`
