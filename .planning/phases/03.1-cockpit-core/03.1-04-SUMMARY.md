**`deliverApprovedPlan` durable workflow fans out the existing governed `gmail.send` step once per recipient row with per-recipient try/catch isolation, plus a `deadLetterRecipient` helper and a dev-deployment fan-out smoke proving SC4 (reach + write-once) and SC5 (isolation + redaction).**

## Accomplishments
- `deliverApprovedPlan` workflow: loops `gmail.send` per recipient row, transitioning each row's status independently; a terminal send throw is caught, dead-lettered on its own correlationId, and the loop continues (SC5) while the workflow still returns `success` (onComplete archives nothing).
- `deadLetterRecipient` internalMutation: per-row DLQ mirroring `onPipelineComplete`'s three writes (deadLetters row + `deadletter.written` audit + `status:"failed"` + one idempotent `failed` telemetry row), payloads carrying the `requestId` ref ONLY.

## Decisions Made
- Passed `correlationIds` as an array parallel to `requestIds` into the workflow (deterministic, no extra read inside the handler) rather than reading each cid back from its row.
- Kept `onPipelineComplete` wired as the workflow's onComplete catch-all: with per-row try/catch the workflow returns `success`, so it archives nothing — correct, no conflict with the per-row DLQ.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Added a `SMOKE::fail` throw sentinel to gmail.send**
- **Found during:** Task 2 (fan-out isolation smoke)
- **Issue:** The isolation assertion needs one recipient's send to throw *terminally* offline, but `gmail.send` for the tokenless `"smoke"` tenant returns `{ delivered:false }` (never throws), and no other offline path produces a terminal throw. The plan said to "reuse the SMOKE::fail convention," but no such sentinel existed and `gmail.ts` was not in the plan's `files_modified`.
- **Fix:** Added a 3-line content sentinel at the top of `gmail.send` — `if (req.subject.startsWith("SMOKE::fail")) throw ...` — mirroring the blessed `llm.ts` `fail=primary` sentinel precedent. The message carries no PII; real rows never start with it.
- **Files modified:** packages/backend/convex/gmail.ts
- **Verification:** `smoke:fanout` green (the forced row dead-letters in isolation); `smoke:pipeline` regression green (its `SMOKE::route` goals never start with `SMOKE::fail`).
- **Committed in:** `6bd5594` (Task 1 commit)
