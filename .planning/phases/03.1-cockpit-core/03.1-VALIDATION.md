---

## Sampling Rate

- **After every task commit:** Run the touched package's quick command (`vitest run <file>` / `typecheck`)
- **After every plan wave:** Run `pnpm test` + relevant `smoke:*`
- **Before `/gsd:verify-work`:** Full suite + `smoke:fanout` + Playwright E2E green
- **Max feedback latency:** ~60 seconds (unit + one smoke flow)
