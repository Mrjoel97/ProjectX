G5 → plan-row ADR → G6/G10 · `readPage` + staleness + skill v4 · no bake-off.

## Tasks

1. **`readPage`** on the research record (`buildWebResearchTool`, llm.ts): Tavily `/extract` at `basic`
   depth with the model's `focus` as the rerank query; accepts ONLY a URL that `webResearch` returned in
   this run (a Set inside the record — structural, before any network call); ≤ `PAGE_READS_PER_RUN`
   reads, `PAGE_READ_CHARS` cap; missing key / failed extraction / HTTP error / unscannable focus all
   return a note, never a throw. Fee: `pageReadFeeUsd` (a fifth of a search) on the same web-fee row.

4. **Staleness:** `RESEARCH_STALE_AFTER_MS` in core — the reuse window in dispatch AND the memo card's
   retrieval stamp ("may be out of date", words not colour).
5. **Honesty:** `LIMITS_FOOTER` rewritten (the "executed by the model provider" sentence has been false
   since the Tavily move); `research.test.ts` asserts the new sentence and the absence of the old.
6. **Skill v4** (`research-specialist.md` → regenerated constant): three tools, "Read before you cite",
   page-read / snippet-only labels, the limit section rewritten. Published as a candidate by
   `seedSkills`, gated by `pnpm eval:golden --skill research-specialist@<v>` on the local deployment,
   activated there; production activation is the owner's G19 step.
