# 40-03 — The PDF shows up where the work is, and the Office decision is written down

**Source:** `40-RESEARCH.md` §1.2, §3 steps 1 and 3, §6 decision 2 (owner: eager for the open
thread's newest artifact only).

## Tasks

1. **Inline PDF in `OutputCard`** (`cards.tsx`, the preview `<section>`): when the SELECTED created doc's
   bytes are `application/pdf` (`vaultDocText.storedMimeType`), mount `<iframe src={url} title=…>` with
   the PreviewModal's props (no `sandbox`; `height: min(70vh, 32rem)`; the card is the single scroll
   owner), the markdown text beneath as today; "Open full document" unchanged. The URL comes from ONE
   `useQuery(api.vault.vaultDownloadUrl)` gated on `selectedId` + PDF bytes — the newest doc by default,
   an older one only after the user picked it. When the selected doc is a `sheet`, the existing
   `MarkdownDocument` tables ARE the grid (no second path). Copy stays "Saved to your vault. Nothing was
   sent." (e2e-pinned).
2. **The URL rule, rewritten once:** `content.ts:165-170` and vault.md's sentence become "a bearer
   capability is minted only for a row the user is looking at — the open thread's selected created
   artifact, or a row they clicked — and never sits in a subscription for a row nobody is viewing"; a
   source-scan test in `outputCard.test.ts` pins that `api.vault.vaultDownloadUrl` appears exactly once in
   `cards.tsx`, inside `function OutputCard`, gated on `selectedId`.
3. **ADR-036 "Office fidelity: PDF twin, text projection, `.xlsx` out"** — Status Accepted 2026-09-06;
   Context (08-21 audit, what shipped before this phase, the three planes); Decision (generation set is
   `pdf | html | xlsx`, never DOCX/PPTX — no library, no sidecar; every long agent document carries a PDF
   twin; uploads are viewed as text projection + original download, spreadsheets as a capped structured
   grid from a separate table; the browser's own PDF viewer in an un-sandboxed iframe is the PDF surface;
   an HTML preview, when built, never shares that element or policy); Options considered (pdf.js, mammoth
   /docx-preview, LibreOffice sidecar, client-side SheetJS — each rejected with the constraint);
   Consequences (the `officeText` flatten bar is now a decision; `DocFormat` is the closed set the badges
   derive from; `vaultSheets` caps are honesty-flagged; no per-document fee). Never edits a prior ADR.
4. **Close:** `DOC-01` minted under `### Document canvas (minted 2026-09-06 — Phase 40, Track C step 11 /
   G5)` + traceability row Complete; ROADMAP Phase 40 block + `| 40. … | 3/3 | **Complete …** |` row;
   STATE.md (ONE frontmatter block; closes table; next = Phase 41 plan-row ADR); production-beta.md G19
