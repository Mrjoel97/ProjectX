## Decisions Made
- Conservative WinAnsi keep-set (0x20-0x7E, 0xA0-0xFF) — errs toward dropping rare glyphs (euro/trademark) to guarantee drawText never throws. The renderer's try/catch is a defense-in-depth net.
- Inline `jsonSchema<{title,markdown}>` in llm.ts rather than a new @pikar/contracts schema file — reuses the SDK's `jsonSchema` the tools already import; keeps the adapter zod-free and the file list minimal.
- Title arg → PDF `/Title` metadata (not a re-rendered heading), since the drafter markdown carries its own `#` heading.
