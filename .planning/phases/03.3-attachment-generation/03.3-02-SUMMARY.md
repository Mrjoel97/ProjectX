## Decisions Made
- `attachmentUrls` returns `[]` on tenant mismatch (soft-guard, mirrors `byThread`) rather than throwing — a cross-tenant caller sees nothing.
- `recordAttachments` sets/clears `attachmentError` directly (passing `undefined` removes it), so the error-clear on a successful generate is unambiguous and never has to special-case the drop-undefined `patchPlan`.
- `reportForPlan` persists and resolves the send-time `attachmentRefs` → immutable storage id → `getUrl` (never regenerate) so REPORT re-downloads the EXACT bytes that were sent.
