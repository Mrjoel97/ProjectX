## Accomplishments
- `buildMime` gained an optional `attachments` param: zero → the EXACT legacy plain-text string (byte-identical, V4); one+ → `multipart/mixed` with a `=_pikar_<hex>` boundary, a base64 text/plain body part, one `application/pdf` part per attachment (STANDARD base64 wrapped 76), and a mandatory closing `--boundary--` (V3).
- `send` loads each resolved attachment's bytes via `ctx.storage.get(storageId)` after the token refresh and before assembling the MIME; a missing blob throws (→ retrier → onComplete DLQ), never a silent bare send.
- `getForDelivery` resolves `requests.attachmentRefs` → `[{filename, mimeType, storageId}]` (dangling refs dropped) alongside the existing delivery fields.
- Governance preserved verbatim: `gmail.sent` audit stays refs-only; `awaiting_reauth` hold, transient-500 retry throw, and the `SMOKE::fail` sentinel are untouched; inner parts base64, only the whole raw message base64url.
