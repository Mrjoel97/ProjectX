      price via `priceUsage("openai/gpt-4o-mini", usage)` and `recordSpend`.
    - text/document → UTF-8 decode (NO model, NO spend).

    Shared `runIntake(ctx, {threadId, storageId, filename, mimeType, size, isDictation}): Promise<{threadId}>`:
      1. preCall gate (kill-switch/budget) BEFORE the model call — a stop returns a conversational
         "paused" reply, marks NO artifact model call (mirror the cockpit's blocked-as-data, never a throw).
      2. load bytes: `ctx.storage.get(storageId)` → Uint8Array.
      3. `classify(bytes, mimeType, filename)` → kind (dictation forces the audio path).
      4. insertArtifact status="uploaded" → patch "extracting".
      5. EXTRACTION MODEL CALL (the bounded GRDL-01 exception): audio→transcribe, image/pdf→extractVisual,
         document→UTF-8, unknown→conversational reject (status="failed", NO model call, STOP). → rawText.
      6. `scanText(rawText)` FAIL-CLOSED: on Err/unknown → patchArtifact status="failed", write NO safeText,
         write NO raw text anywhere, surface a conversational error, STOP (no audit of raw, no merge).
      7. patchArtifact status="extracted", extracted = safeText (REDACTED content plane; §4 keeps it out of audit).
      8. audit "intake.extracted" { artifactId, kind, piiCounts, charCount } — refs/counts ONLY (§4), NEVER rawText/safeText.
      9. MERGE: `ctx.runAction(api.cockpit.sendCockpitMessage, { threadId, text: frameForConversation(kind, filename, safeText) })`.
         For dictation, frameForConversation returns safeText verbatim (the transcript IS the request).

    Public actions (tenantAction, explicit Promise<{threadId}> return types):
    - `attachToThread({ threadId, storageId, filename, mimeType, size })` → runIntake(isDictation:false).
    - `dictateToThread({ threadId, storageId })` → runIntake(isDictation:true) (audio path, verbatim frame).
