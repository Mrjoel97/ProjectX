MediaRecorder one-shot (native, no dep):
```typescript
const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
const rec = new MediaRecorder(stream);
const chunks: Blob[] = [];
rec.ondataavailable = (e) => chunks.push(e.data);
rec.onstop = async () => { const blob = new Blob(chunks, { type: rec.mimeType }); /* upload → dictateToThread */ };
rec.start(); /* ... user clicks stop ... */ rec.stop();
```
