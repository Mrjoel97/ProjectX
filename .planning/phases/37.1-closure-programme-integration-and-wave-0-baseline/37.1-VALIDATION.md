## Sampling Rate

- **After every task:** run both planning checks and `git diff --check`.
- **After checker-source changes:** also run focused new tests and free-gate self-test.
- **After every plan wave:** run planning checks, playbook freshness, affected typechecks/tests.
- **Before `$gsd-verify-work`:** the documented offline integration checkpoint must be green or the
  phase verification must remain `gaps_found` with the exact failing command.
- **Max feedback latency:** under 30 seconds for planning-only edits.
