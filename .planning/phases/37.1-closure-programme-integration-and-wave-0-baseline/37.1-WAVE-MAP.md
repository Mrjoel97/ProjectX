## Shared programme rules

- The integration owner named below owns shared contracts and reconciles parallel lanes; lane owners
  do not make uncoordinated edits to shared hotspots.
- `Implemented`, `offline-tested`, `deployed`, `live-observed`, `owner-accepted`, and
  `externally-enabled` remain separate facts.
- External-only work enters Wave 7 only after its technical owner has produced a complete, disabled
  or safely bounded re-entry packet.
- Every wave stops on ambiguous source identity, weakened tenant/approval/audit boundaries, an
  unbounded paid or irreversible action, or evidence that cannot be tied to an exact revision.

## Programme stop conditions

Stop the active lane and return to the integration owner when a dependency is not satisfied, a
shared-file owner is ambiguous, two rows claim the same integration responsibility, a provider or
legal condition is used to excuse unfinished repository work, evidence would be inferred across
layers, or the requested action exceeds its authorization. Wave 8 additionally stops if any enabled
surface is not tied to the same exact production revision.
