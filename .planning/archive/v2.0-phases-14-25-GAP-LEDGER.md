**B2 · Microsoft disconnect posture (Gate 1, 25-06 Task 2). → DECIDED 2026-08-17: POSTURE A.**

**The re-verification found a defect the packet had introduced and the shipped UI already carries.**

personal/work accounts". It is neither. Personal accounts use
`https://account.microsoft.com/privacy/app-access`; work/school accounts use

"Microsoft My Apps" — the work/school portal — so a personal-account beta user, which the beta
mostly will be, was sent somewhere that will not show them Pikar. **FIXED — owner approved the
wording and it LANDED 2026-08-17.** Both routes are named in the confirm and LINKED in the success
note (`note` widened `string` → `ReactNode`), matching the URLs `DataControls.tsx` and the privacy
page already shipped. `connectionsSurface.test.ts`'s guard was **tightened** — it accepted the bare
string "My Apps", which is precisely how the wrong portal survived review — and now requires both
hostnames; mutation-proven red-then-green. **B2 is fully closed.** GOVN-03's provider-revocation
clause stays open, as both postures always implied.
