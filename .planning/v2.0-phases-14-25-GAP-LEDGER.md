### Group B — blocked on an OWNER DECISION (3)

Nothing can be built until these are answered. Each is a judgement, not a run, and none costs money.

**B1 · ACTN-02 — the Microsoft calendar-management fork.** `17-GRAPH-CONCURRENCY-PROBE.json`,
captured 2026-08-16 against a real MSA:

- `stalePatchStatus: 412`, `stalePatchPreserved: true` → conditional **UPDATE is atomic and safe**.
- `staleDeleteStatus: 204`, `staleDeletePreserved: false` → Graph **ignores `If-Match` on DELETE**.
  A stale-ETag delete destroyed the event. There is no optimistic-concurrency seatbelt on the
  delete path at all.
- `supported: false` → 17-08's gate is NOT met.

17-07's own recorded fallback is: Microsoft stays create-only, Google keeps management, ACTN-02
stays pending. But the binary gate hid a third option the measurement actually supports. The fork:

| Option | What ships | Cost |
|---|---|---|
| **A** — Microsoft UPDATE-only | Governed update on both providers; cancel/delete Google-only. Honest, and the 412 proves it atomic. | 17-08 must be re-cut. ACTN-02 closes as "management, minus Microsoft delete". |
| **B** — Google-only management | Microsoft stays create-only. Smallest diff. | ACTN-02 closes narrower than its wording. |
| **C** — hunt an atomic Graph delete | Research a Microsoft-documented delete primitive with concurrency protection. | Unbounded; may not exist. |

Forbidden in all three, and more tempting now than before: unconditional PATCH/DELETE, and
GET-then-compare `changeKey`. Both are read-modify-write races.

**B2 · Microsoft disconnect posture (Gate 1, 25-06 Task 2).** The disconnect UI copy is
deliberately unwritten because the wording *is* the decision. Needs
`25-MAIL-MIGRATION-EVIDENCE.md` read, the three Microsoft doc links re-verified, Posture A or B
chosen. Costs nothing, blocks nothing else. **Do it first.**

**B3 · ADR-022 acceptance (Gate 2, 25-10 Task 2).** `docs/decisions/022-beta-domain-posture.md` is
written and sits at `Proposed`. Enforcement is already wired and green (`ops.envCheck` →
`nonDurableOrigins`, surfaced on `/admin`). It needs `Status: Proposed` → `Accepted` and a date —
nothing more.
