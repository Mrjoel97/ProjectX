# The Value Equation

The core engine of every Grand Slam Offer. Value is not a feeling you assert — it is a ratio you engineer. All four drivers are **perception**, which means all four are yours to move.

```
              (Dream Outcome) x (Perceived Likelihood of Achievement)
    Value = ----------------------------------------------------------
              (Perceived Time Delay) x (Perceived Effort & Sacrifice)
```

## The four drivers

| Driver | Direction | What it is | How to move it |
|---|---|---|---|
| **Dream Outcome** | INCREASE | The gap between their reality and their dreams; the feeling they're really buying. | Sell a bigger destination; tie it to **status** (how they'll be perceived). |
| **Perceived Likelihood of Achievement** | INCREASE | Their belief it will actually work *for them*. "People pay for certainty." | Proof, track record, testimonials, guarantees, credible mechanism. |
| **Perceived Time Delay** | DECREASE | How long until they get the result — including the *first* result. | Long-term outcome + short-term experience; engineer fast early wins. "Fast beats free." |
| **Perceived Effort & Sacrifice** | DECREASE | The work, hassle, and things they must give up. | Move from "do it yourself" toward "done for you." Remove steps. |

## The division rule (why the bottom matters most)

Value is a **division**, not a sum. Driving the denominator (Time Delay x Effort & Sacrifice) toward **zero** sends value toward **infinity**. Amateurs pile on more dream-outcome hype; **pros attack the bottom** — they make it faster and easier. When scoring an offer, the biggest lift almost always comes from cutting time or effort, not adding more promise.

## The diagnostic (the "father's four questions")

Run every prospect's silent objections through these — they map one-to-one to the four drivers:
1. **What will I make / get?** → Dream Outcome
2. **How will I know it's going to work (for me)?** → Likelihood
3. **How long will it take?** → Time Delay
4. **What's expected of me?** → Effort & Sacrifice

## The comparison rule

When two offers promise the **same dream outcome**, the dream-outcome terms cancel out of the ratio. Price is then set entirely by the **other three drivers** — likelihood, time, and effort. This is how you beat a competitor selling the "same" result: be more certain, faster, and easier. It is also why "we do the same thing but cheaper" is a losing position — it competes on none of the three levers that remain.

## Convergent vs divergent thinking (for generating drivers)

- **Convergent** = one right answer (narrowing).
- **Divergent** = "Multiple Variables, Known & Unknown, Dynamic Conditions, Multiple Answers" (expanding). Offer creation is a *divergent* task — generate many options before trimming.
- **Brick Exercise** (to warm up divergent thinking): 120-second timer, list every use for a brick; then vary its attributes (size, material, shape, holes) and list more. Use the same move on your offer — vary the delivery attributes to find non-obvious value.

## Score it

Use `scripts/value_equation_scorer.py` to grade an offer 1-10 on each driver, compute the value index `(dream x likelihood) / (time x effort)`, and surface the single weakest driver plus the lever to pull.
